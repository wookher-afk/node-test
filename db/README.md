# NODE DB 0.1

PostgreSQL 기반 초기 관계형 스키마 초안입니다. `001_foundation.sql`은 핵심 엔터티의 출발점일 뿐, 확정된 모든 요구사항을 구현하지 않습니다.

실행 예: `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f db/001_foundation.sql`

**아직 미구현:** 실제 인증·권한 검증, 장비 소유권, 운송 요청/완료, 일정 충돌 차단, 날짜별 모집 정원 원자적 확정, 지급 수령자 검증, 감사 로그, 신고 처리, 개인정보 보호, API/UI, 테스트. 운영 환경에 바로 배포하지 마세요.

다음 단계: 전체 요구사항 추적표, 정규화/제약 검토, 날짜별 정원·중복 예약의 트랜잭션 테스트, 인증과 권한 설계.
