# 업체 등록 주소·모집유형·단계별 분류 수정 — 2026-11-01

미리보기: http://127.0.0.1:8048/company-registration

## 구현

- 현장 기본주소는 읽기 전용이며 ‘도로명주소 검색’으로 도로명 또는 지번주소를 검색·선택한다. 검색은 페이지 안에 Kakao 우편번호 서비스를 표시하며, 상세주소는 별도 입력한다. 로딩 실패·시간초과는 안내 후 재시도할 수 있다. 기존 재사용 주소 검색 컴포넌트는 없었다. 공식 가이드: https://postcode.map.kakao.com/guide
- 기존 `worksite.address`는 기본주소와 상세주소를 결합한 문자열로 유지한다. JSON 문서에 `baseAddress`, `detailAddress`, `postcode`를 추가하며 DB 스키마 변경은 없다. 서버는 추가 필드의 형식·길이와 결합 주소 일치를 검사한다. 과거 문자열 주소는 임의로 분해하지 않고 그대로 표시·보존한다. 새 주소 선택 시 상세주소를 초기화한다.
- 모집유형 선택지는 정확히 ‘기술 및 일반작업자’, ‘장비기사만’, ‘장비+장비기사’다. 저장값은 각각 `technical_worker`, 기존 `worker`, 기존 `equipment_with_operator`다. 기존 `worker`는 중장비 기사 의미를 보존한다.
- 기존 `either` 문서는 API 및 목록에서 보존한다. 이 항목을 편집하면 이전 ‘모두 가능’ 유형임을 안내하고 세 가지 새 유형 중 하나를 명시적으로 선택해야 한다. 자동 변환하지 않는다.
- 두 장비 유형은 작업자와 같은 `NODE_CATALOG.version=2`의 공통 31종 분류표를 사용한다. 대분류 → 중분류 → 소분류 → 형태 → 규격 → 옵션 순서로 필요한 항목만 노출한다. 형태는 작업자와 동일하게 규격 후보 결정에 필요하므로 유지했다. 부모/모집유형 변경 시 종속 선택과 옵션·직접입력을 초기화한다. 전체 분류가 완성되지 않으면 모집항목을 추가할 수 없다.

## 기술·일반 직종 정책 결정 필요

현재 공통 카탈로그에는 중장비 항목만 있으며 기술·일반 직종용 공통 분류 데이터가 없다. 해당 유형을 선택하면 중장비 필드를 완전히 숨기고 분류표 미정 안내를 표시한다. 임의 직종이나 중장비 ID를 대신 저장하지 않으며 이 유형의 신규 항목 저장은 차단한다. 기존 장비 모집의 저장은 가능하다.

필요한 결정: 기술/일반 직종의 공식 목록·안정적인 ID·상하위 관계·작업자 등록과 공유할 원천 및 직종별 경력/자격 조건. 이 데이터 확정 전에는 기술·일반 모집 등록을 완성했다고 볼 수 없다.

## 검증 결과

- 별도 폐기용 `node_test_company_20261101`에서 전체 서버 회귀 **137/137 통과**, 실패·건너뜀 0. 새 주소 필드의 결합 검사, 기존 세 모집유형 호환, 미정 기술 유형 거부 포함.
- 최신 코드로 로컬 8048 서버 재시작 후 Chrome **390px/1440px** 실DB 검사 통과: 정확한 선택지, 기술 유형 장비 필드 숨김·추가 차단, 단계 노출, 부모 변경 초기화, 복수 항목, 저장·수정·새로고침·로그아웃/재로그인 복원, 급여·일정·경력·옵션 호환, 충돌·잘못된 ID 거부. 페이지 오류·가로 넘침 없음.
- 자동화된 저장 왕복 검사에서는 외부 검색 선택 콜백만 합성 응답으로 주입했다. 별도로 **실제 Kakao 검색 서비스**를 Chrome 390px에서 열고 ‘사직로 161’ 검색 → ‘서울 종로구 사직로 161’ 결과 클릭 → 기본주소 반영 → 상세주소 ‘2층’ 입력까지 확인했다. 실제 검색 동작과 실DB 왕복은 구분된 검증이다.
- 390px/1440px 캡처 시각 확인. JavaScript 구문 검사 및 `git diff --check` 통과.
- 미리보기 DB 검증 전 **57개 테이블의 기존 177개 행 해시가 검증 후 모두 일치**했다. 합성 검증 계정·등록 문서만 추가했다. 미리보기 DB 초기화·마이그레이션은 하지 않았다.
- 기존 미커밋 파일을 초기화하거나 되돌리지 않았다. 이번 제품 변경은 `web/company-registration.html`, `ui/03-2/company-registration.js`, `server/company-registration.js`에 한정했다. 단위 테스트 확장, 새 UI 검증 스크립트와 이 보고서·증거를 추가했다.

## 제약

- 기술·일반 직종 분류가 미정이므로 해당 유형 신규 등록은 보류 상태다.
- 외부 주소 검색은 네트워크 및 Kakao 서비스 가용성에 의존한다. 과거 문자열 주소의 상세주소 자동 분리는 하지 않는다.
- 실제 모바일 기기·Safari/Firefox 검증은 하지 않았다. 실제 외부 주소 검색 선택은 390px Chrome에서 확인했고, 1440px 저장 왕복은 합성 검색 콜백으로 검증했다.
- 푸시·배포·병합·커밋, 자동매칭·알림·수락은 수행하지 않았다.
