- 정책 문서 등록과 실제 코드 구현은 별개로 관리한다.
- 사용자가 승인하지 않은 정책은 확정 상태로 기록하지 않는다.

- 귀책의 등록·인정 근거와 이견 처리: NODE가 귀책을 판정하지 않는 원칙과 연결 필요.

- 정원 축소 시 날짜별 취소 단위와 확정 시각 동률 처리.
- 매칭권 잔액 부족 시 처리, 보관분의 양도·사용 순서·회계 처리.
- P-05의 업체 보관분은 즉시 대체 실패로 소멸하지 않는다는 확정 원칙을 유지한다.
