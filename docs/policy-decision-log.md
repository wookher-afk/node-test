- P-44·49: 제출 내역의 열람 가능/기간 만료/권한 철회 관리와 미열람/열람 완료/기간 만료/권한 철회 상태 표시를 연결한다. 수신 업체·제출일·공개 정보·유효기간·현재 상태와 업체별 열람 기록을 본인이 확인한다. 최초 열람 시각은 반복 열람에도 유지하고 철회 후 제출 이력도 보존한다. 상태가 겹칠 때의 표시 우선순위와 내부 상태 구조는 미확정으로 남긴다.

### 중복·정합성 검토

1. **SM-01 / 헌법 제14조·DB-008:** 기존 원칙은 빈 일정만으로 가능 의사를 추정하지 않으며 기본 근무 요일·일정·예외로 가능일을 산출한다. 신규 정책에는 작업자가 자동 모드를 직접 선택하는 의사표시가 있다. 따라서 빈 일정만으로 모든 사용자에게 자동 모드를 적용하는 근거는 아니다. 다만 자동 모드 선택 시 기본 근무 요일 밖의 빈 날짜까지 포함하는지, 기존 기본 근무 요일보다 모드 설정이 우선하는지는 문언상 미정이다. 기존 원칙을 변경하지 않고 추가 결정 대상으로 남긴다.
2. **SM-02·07~09 / B8-14·15:** B8-14·15의 수신 중지·기존 제안 유지·무기한/기간 지정 중지·재개와 내용상 중첩된다. 이번 정책은 모드·선택 날짜·반복 휴무 보존 및 자동 해제 시각 등을 구체화한 별도 확정 묶음이다. 기존 B 정책을 복사해 다시 번호 매긴 것으로 처리하거나 폐기하지 않는다. 일반 수신 중지와 자동 모드 일시정지의 설정 연동·동일 상태 여부는 확정하지 않는다.
3. **SM-05·06·08 / B8-10·19·41:** 휴무·자발적 수신 정지는 이미 받은 제안의 자동 거절이나 확정 계약 취소가 아니다. 기존 제안 수락은 계약 확정과 별개이며 신규 원문 자체도 확정 근무 일정과 충돌 시 수락을 금지한다. 양측 승인·확정 직전 자격/장비/일정/정원 재검증을 폐기하는 내용은 없다.
4. **SM-08 / B8-59·67:** 자발적인 매칭 일시정지는 응답기한을 연장하지 않지만 신고에 따른 사건별 지원·제안 중지는 남은 응답시간을 보존한다. 사유·범위가 달라 단독 적용에서는 모순이 아니다. 두 중지가 동시에 적용될 때 기한 계산·재개 우선순위는 새 판단이 필요하므로 임의로 결정하지 않는다.
