# 03-3 화면 단순화

긴 상단 안내를 접고 ‘내 장비의 면허 → 면허 등록’을 먼저 표시했다. 법정 매핑 설명은 ‘어떤 면허를 등록하나요?’에 보존했다. 다른 면허·자격·교육 추가, 상세 등록 내용, 선택 상세 입력, 이전 기록·복구 기능은 펼쳐보도록 변경했다. 입력 중에는 장비·등록 목록을 숨겨 현재 질문에 집중하도록 했다. 버튼·질문은 일상적인 표현으로 줄였다.

기존 저장키·스키마·보유 추정 금지·미확인 상태·원문 보존·잠금 로직은 유지. 화면 12개 및 모델 8개 회귀 통과. 320/390px 실제 8033 기본 화면 캡처, 가로 넘침 없음, 390px 직접 시각 확인. 큰글씨·단계 배치·초안 복원·왕복 이동은 화면 회귀에 포함된다.

변경: ui/03-3/index.html, app.js, style.css; tests/ui/03-3.test.cjs(접힌 메뉴를 명시적으로 여는 검증); 본 문서. 커밋·푸시·배포·병합 없음.

## 취득일 선택 수정

‘언제 취득했나요?’와 ‘정확히 앎/모름’ 메뉴를 제거했다. ‘취득일’ 아래 연·월·일을 직접 선택한다. 연도는 한국 시간 기준 현재 연도(2026)부터 내림차순으로 제공하며, 현재 연도의 월·일도 오늘 이후를 제외한다. 월별 일수·윤년을 반영한다. 기존 날짜·모름 기록은 자동 변환하지 않고 기존 저장 형식과 구 기록을 보존한다. 날짜를 수정할 때는 수정 전 저장 날짜를 이력으로 보관한다. 부분 선택도 초안으로 보관한다.

화면 13/13, 모델 8/8 통과. 연도 내림차순·미래 연도 제외·취득일 메뉴 제거·날짜 초안 복원·윤년 변경·원래 날짜 이력 보존 검증 포함. 390px 큰글씨 날짜 선택 화면 직접 확인, 320/390/1440px 단계 배치 회귀 통과.

## 면허번호 필수 입력

면허 유형 첫 단계에 면허번호(필수)를 추가했다. 공백만 입력한 번호는 다음 단계·목록 저장에서 차단하고 입력란으로 안내한다. 앞뒤 공백은 목록 저장 때 제거하며 문자·숫자·하이픈·앞자리 0은 그대로 보관한다. 번호 형식으로 진위나 법정 적합성을 판단하지 않는다. 국가기술자격·교육·기타에는 요구하지 않는다.

동일 저장키에 선택적 licenseNumber 필드를 추가하여 기존 번호 없는 기록을 읽고 변경 없이 보존한다. 새 면허 또는 수정한 면허는 Store에서도 번호를 검증한다. 번호가 없는 기존 면허에는 보완 안내를 표시한다. 미완성 초안은 번호 없이 임시저장 가능하다.
