# NODE B 운영정책 확정 기록

> 상태: 사용자 대화에서 명시적으로 확정한 정책만 기록. 문서화는 기능 구현·배포 승인이 아니다.
> 기존 P-01~P-50 원문 및 NODE 기본 원칙은 유지한다. 충돌 가능성이 있는 부분은 별도 정합성 검토 대상으로 남긴다.

## 등록 묶음 1 — B1~B6, B7-1~B7-4 (10개 결정)

### B1 — 분쟁과 귀책 판정
- NODE는 당사자 간 거래 분쟁을 직접 중재하거나 귀책을 임의 판정하지 않는다.
- 본인의 인정, 양측 합의 또는 검증 가능한 공적 결정으로 확인된 경우에만 귀책을 확정한다.
- 일방 주장만 존재하면 미확정으로 유지하고 제재하지 않는다.

### B2 — 우천 취소
- 업체의 우천 취소 통보를 작업자가 인정하면 우천 취소로 기록한다.
- 이 경우 귀책 취소나 보상 대상으로 처리하지 않는다.
- 작업자가 동의하지 않거나 응답하지 않으면 사유를 미확정으로 유지한다.

### B3 — 업체 귀책 취소 시 작업자 보상
- 업체 귀책이 확정되면 작업자에게 유효기간 1년의 무료 매칭 이용권 1회를 즉시 지급한다.
- 업체 청구와 작업자 이용권 사용은 독립적으로 처리한다. 발급 시점에는 표준 매칭 수수료를 업체에 청구하고, 실제 사용 시 면제된 실제 수수료와 정산한다.
- 이용권이 사용되지 않은 채 만료되면 발급 당시 청구액을 유지한다.
- 귀책이 뒤집히면 미사용 이용권을 회수한다. 이미 사용한 혜택은 작업자에게서 환수하지 않으며 업체 청구를 정정·환급한다.
- 발급·사용·청구·정정의 감사 이력을 보존한다.

### B4 — 작업자 귀책 취소 시 처리
- 작업자 귀책이 확정되면 매칭 이용권 1회를 차감한다. 잔여 이용권이 없으면 현금 채무가 아닌 차감 대기로 기록하고 이후 충전분에서 자동 차감한다.
- 업체에는 취소된 자리의 최초 확정 대체 인력 매칭 수수료 1회 면제를 제공한다. 차감한 매칭권을 대체 작업자에게 직접 지급하지 않는다. P-05의 피해 업체 긴급 공고 상위 노출 혜택은 유지한다.
- 대체 인력이 없으면 업체 혜택은 다음 구인공고의 첫 확정 작업자에게 이월되며 만료하지 않는다.
- NODE는 작업자 이용권 차감 회수 여부와 무관하게 업체의 면제 혜택을 먼저 부담한다.
- 귀책이 뒤집히면 작업자 이용권을 복원하고 미사용 업체 혜택을 회수한다. 이미 사용된 업체 혜택은 NODE 부담으로 유지한다.
- 차감·대기·혜택 사용·정정 이력을 보존한다.

### B5 — 대금 지급 및 수령 확인
- 업체가 지급 금액·날짜를 신고하고 작업자가 실제 수령 금액·날짜를 독립적으로 확인한다.
- 양측 확인이 일치하는 부분만 확정하며 분할 지급은 회차별로 기록한다. 불일치는 미확정으로 유지한다.
- 미응답·일방 신고만으로 지급 완료나 귀책을 자동 확정하지 않는다.
- 약정 지급일과 실제 지급·수령일의 원본 기록을 보존한다. 작업자는 실제 수령 확인 후 지연 지급분을 정시 지급으로 자발적으로 인정할 수 있으나, 그 금액은 별도의 인정 반영 정시 지급률에만 포함한다. 실제 정시 지급률과 명확히 구분해 표시하며 실제 지급·수령 날짜는 변경하지 않는다.
- 해당 인정은 30일 이내 철회할 수 있으며 승인·철회 시 최근 12개월 및 전체 기간 통계를 재계산하고 과거 스냅샷과 감사 이력을 보존한다.
- 업체의 소급 정시 인정 요청은 작업자의 수령 확인 후에만 허용한다.

### B6 — 계약 지급 일정
- 구인공고에 지급 조건을 지원 전에 명시한다.
- 분할 지급의 각 회차별 약정 지급일·금액을 계약에 기록하고 매칭 확정 시 조건을 고정한다.
- 변경은 양측 동의와 변경 이력을 필요로 한다.
- 기존 약정 지급기일 전에 양측이 합의한 변경 지급일만 NODE 정시 지급 통계의 기준일로 인정한다. 사후 소급 변경은 인정하지 않는다.
- 법령상 지급기일 등 강행 기준은 당사자 합의보다 우선한다.

### B7-1 — 정시 지급률 산식

- 두 지표 모두 금액 가중 방식으로 산정하며 명확히 구분해 표시한다.
- 공통 분모: 양측 확인이 완료된 지급 대상 금액. 산정 대상은 B7-2를 따른다.
- 실제 정시 지급률: 약정 지급일까지 지급된 것으로 양측 확인된 금액 ÷ 공통 분모 × 100.
- 인정 반영 정시 지급률: (실제 정시 지급 금액 + 작업자가 정시로 인정한 지연 수령액) ÷ 공통 분모 × 100.
- 동일 금액을 중복 집계하지 않으며 인정·30일 이내 인정 철회 시 관련 통계를 재계산한다. 실제 지급일 원본은 변경하지 않는다.

### B7-2 — 정시 지급률 산정 대상
- 양측 확인된 지급 건만 분자·분모에 포함한다.
- 아직 지급기일이 오지 않은 금액과 작업자 수령 확인 대기 금액은 산식에서 제외하고 별도 표시한다.

### B7-3 — 기일 경과 후 지급 미확인
- 지급기일이 지났으나 업체 지급 신고가 없는 건은 `지급 미확인`으로 기록한다.
- 해당 금액은 정시 지급률 산식에서 제외하되 경과일·금액·건수를 별도 표시한다.
- 이를 자동으로 미지급 확정이나 업체 귀책으로 판정하지 않는다. 추후 확인되면 통계를 재계산한다.

### B7-4 — 지급 통계 병행 표시
- 정시 지급률을 표시할 때 지급기일 경과 후 미확인 금액과 건수를 반드시 함께 표시한다.
- 정시 지급률만 단독 제시해 미확인 지급 위험이 가려지지 않도록 한다.

## 정합성 및 범위
- B1·B2는 P-08의 분쟁 비중재 원칙과 연결된다.
- B3·B4는 P-03~05의 취소·보상 정책과 연결되며 기존 정책의 세부 수수료·이용권 용어 및 계산 방식은 구현 전 대조한다.
- B5·B6·B7-1~4는 P-07의 지급 확인 및 P-22~23의 통계 재계산 원칙을 구체화한다.
- B7-5 이후 및 B8의 후속 결정은 이 묶음에 포함하지 않는다.
- 이번 등록은 문서화만 수행하며 코드·DB·배포·main 브랜치를 변경하지 않는다.


## 등록 묶음 2 — B7-5~B7-14 (10개 결정)

### B7-5 — 정시 지급률 최소 표본
- 양측 확인된 지급 회차가 1건 이상이면 실제 비율을 표시한다.
- 5건 미만이면 `기록 적음`을 병기하고 0건이면 `산정 기록 없음`으로 표시한다.

### B7-6 — 정시 지급률 대표 기간
- 최근 12개월 통계를 대표 지표로 표시하고 전체 누적 통계를 보조 지표로 제공한다.

### B7-7 — 지급률 기간 귀속
- 최근 12개월 포함 여부는 실제 지급일이 아니라 계약상 지급기일을 기준으로 판단한다.
- B6에 따라 기일 전에 적법하게 합의한 변경 지급기일을 반영한다.

### B7-8 — 작업자 계약 완료율 단위
- 계약 완료율은 근무일수가 아니라 확정된 계약 건수를 단위로 산정한다.
- 실제 근무일수는 별도 이력·지표로 표시한다.

### B7-9 — 비귀책 중도 종료
- 어느 당사자의 귀책도 아닌 중도 종료 계약은 작업자 계약 완료율의 분자와 분모에서 제외한다.
- 중도 종료 사유와 실제 근무 이력은 보존한다.

### B7-10 — 귀책 미확정 중도 종료
- 귀책이 확인되지 않은 중도 종료 계약은 `귀책 미확정`으로 표시하고 완료율 산식에서 제외한다.
- 추후 귀책 확정 시 통계를 재계산한다.

### B7-11 — 작업자 귀책 중도 종료
- 작업자 귀책이 확정된 중도 종료 계약은 작업자 완료율 분모에 포함하고 분자에는 포함하지 않는다.
- 확인 근거와 실제 근무일수를 보존한다.

### B7-12 — 업체 귀책 중도 종료
- 업체 귀책이 확정된 중도 종료 계약은 작업자 완료율의 분자·분모에서 제외한다.
- 업체 측 계약 이행 기록에는 별도 반영한다.

### B7-13 — 계약 완료의 양측 확인
- 계약 전체의 완료는 작업자와 업체가 모두 확인해야 확정한다.
- 한쪽의 미응답은 `완료 확인 대기`로 남기며 자동 완료 처리하지 않는다.
- 확인 대기 건은 완료율 산식에서 제외하고 별도 건수를 표시한다.

### B7-14 — 계약 완료 확인 불일치
- 양측의 완료 여부가 다르면 `완료 확인 불일치`로 기록하고 완료율 산식에서 제외한다.
- 양측 합의 또는 검증 가능한 공적 결정으로 확인되면 기록과 통계를 갱신한다.
- NODE가 거래 당사자 간 귀책을 임의로 판정하지 않는다.

## 등록 묶음 3 — B7-15~B7-21, B8-1~B8-3 (10개 결정)

### B7-15 — 작업자 계약 완료율 기간
- 최근 12개월 완료율을 대표 지표, 전체 누적 완료율을 보조 지표로 표시한다.
- 기간 귀속은 계약상 예정 종료일을 기준으로 한다.

### B7-16 — 작업자 완료율 최소 표본
- 산정 가능한 계약이 1건 이상이면 실제 비율을 표시한다.
- 5건 미만은 `기록 적음`, 0건은 `산정 기록 없음`으로 표시한다.

### B7-17 — 작업자 완료율 공개 범위
- 업체는 작업자 선정 전에 P-15·16의 공개 범위 내 신뢰 통계를 확인할 수 있다. 자동매칭으로 추천받은 작업자의 계약 완료율도 계약 확정 전에 확인할 수 있다.
- 이 공개에 개인별 상세 근무 기록과 분쟁 내용은 포함하지 않는다. 상세 기록의 별도 당사자 열람·본인 제출은 P-36·38을 따른다.
- 신규·무이력 작업자는 이력이 없다는 이유만으로 자동매칭에서 제외하지 않는다.
- 매칭 관계 종료 후 열람 기한과 범위는 B14 후속 검토 사항이다.

### B7-18 — 업체 계약 이행률
- 업체의 계약 이행률을 계약 건수 기준으로 산정한다.
- 정상 완료 계약은 분자·분모에 포함하고 업체 귀책 중도 종료는 분모에만 포함한다.
- 작업자 귀책·비귀책·귀책 미확정 중도 종료는 산식에서 제외하고 별도 기록한다.
- 최근 12개월을 대표 지표, 전체 누적을 보조 지표로 제공한다.

### B7-19 — 업체 이행률 공개 범위
- 업체의 공고를 열람하거나 지원하는 작업자에게 해당 업체 계약 이행률을 제공한다.
- 관계없는 계정에 무차별 공개하지 않는다.

### B7-20 — 업체 이행률 최소 표본
- 산정 가능한 계약이 1건 이상이면 실제 비율을 표시한다.
- 5건 미만은 `기록 적음`, 0건은 `산정 기록 없음`으로 표시한다.

### B7-21 — 지표 독립성
- 계약 완료, 출근·근무, 지급 관련 지표는 각각 독립적으로 관리한다.
- 동일 사건을 동일 지표에서 중복 집계하지 않는다.
- 여러 지표를 가중 합산한 단일 종합 신뢰점수는 만들지 않는다.

### B8-1 — 기록 없음과 0% 구분
- 산정 가능한 기록이 없으면 `산정 기록 없음`으로 표시한다.
- 실제 산정 결과가 0%인 경우와 명확히 구분하며 신규 사용자에게 임의의 초기 점수를 부여하지 않는다.

### B8-2 — 최근 기록 없음
- 최근 12개월에 산정 가능한 기록이 없어도 전체 누적 이력이 있다면 최근 지표는 `산정 기록 없음`으로 유지한다.
- 전체 누적 통계는 별도로 표시하며 최근 지표를 과거 누적값으로 대체하지 않는다.

### B8-3 — 수동 검색의 신뢰지표 정렬
- 해당 신뢰지표에 접근 권한이 있는 사용자의 수동 검색에서만 신뢰지표 내림차순 정렬을 제공한다.
- 동률이면 산정 기록 건수가 많은 순서, 그다음 기본 정렬 순서를 적용한다.
- 사용자가 직접 해당 신뢰지표 정렬을 선택한 경우에만 산정 기록 없는 회원을 뒤에 표시할 수 있다. 이는 신뢰도 감점이나 서비스 이용 제한이 아니다.
- 기본 검색과 자동매칭에서 신규·무이력 회원에게 불이익을 주지 않는다. 자동매칭은 작업 적합도 우선, 신뢰정보 보조 원칙을 따른다.

## 묶음 2~3 정합성

## 등록 묶음 9 — B8-47~B8-56 (10개 결정)

### B8-47 — 특정 상대방 매칭 제외
- 작업자와 업체는 각각 특정 상대방을 매칭 제외할 수 있다.
- 어느 한쪽만 설정해도 양측 간 자동매칭과 직접 제안을 차단한다.
- 설정은 언제든 해제할 수 있다.
- 제외 여부와 사유는 상대방에게 공개하지 않는다.
- 기존 확정 계약에는 영향을 주지 않는다.

### B8-48 — 업체 계정 전체 적용

- 업체가 특정 작업자를 제외한 경우에도 모든 현장에 적용한다.

- 상대방의 제외 설정이 남아 있으면 제한은 유지한다.

### B8-49 — 검색 결과 숨김

- 자동매칭·직접 제안·구인 지원을 차단한다.
- 매칭 제외 관리 화면에서는 본인이 직접 제외한 상대방만 확인·해제할 수 있다.
- 상대방의 제외 설정 여부는 공개하지 않는다.
- 기존 계약과 관련 기록은 보존한다.

### B8-50 — 진행 중인 지원·제안 종료

- 설정 해제 즉시 일반 매칭 대상으로 복귀한다.
