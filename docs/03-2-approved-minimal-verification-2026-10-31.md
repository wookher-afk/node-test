# 03-2 승인된 현장규격 최소 수정 검증

검증일: 2026-10-31 (한국시간)

## 적용 결과

- 현장규격의 기존 위치에 체크 목록 하나를 표시한다. 기존 명칭·표시 순서와 직접 입력 선택지를 유지한다.
- 기존 규격 목록을 가진 11종과 각 해당 형태에 적용한다. 31종 전체 형태를 순회해 목록 수와 적용 여부를 검사했다. 목록이 없는 형태·장비의 기존 단일 입력은 유지한다.
- 기존 select는 카고·장비 제원 코드의 단일 값 호환용으로만 숨겨 유지한다. 화면의 선택 기준은 체크 상태이며, 복수 체크와 직접 입력을 함께 사용할 수 있다. 중첩 label은 제거했다.
- 장비별 초안 안에 형태별 규격·직접 입력 선택을 보관하고, 형태 전환·장비 전환·새로고침 시 복원한다. 다른 형태의 규격을 새 형태에 자동 추가하지 않는다.
- 저장 한 번으로 규격별 독립 ID를 가진 기존 형식의 기록을 생성한다. 수정 대상 기록은 기존 ID와 목록 위치를 유지한다. 초안의 선택 배열과 형태별 선택은 최종 기록에서 제외한다.
- 일괄 저장에서는 동일 장비·형태·규격의 기존 기록을 중복 생성하지 않는다. 보유 모드는 제조사·모델·연식도 비교한다. 기존 기록의 제원을 덮어쓰지 않는다. 기존 개별 추가 흐름은 유지한다.
- 직접 입력이 체크된 기존 규격명과 같으면 한 규격으로 처리한다. 연속 제출로 중복 기록이 생기지 않음을 확인했다. 저장 실패 시 메모리의 기록 목록도 되돌린다.
- 제원 입력은 기준 규격 한 건에만 저장한다. 신규 입력의 기준은 목록 순서상 첫 번째로 선택된 규격이며, 수정 시에는 선택에 남아 있는 원래 규격이다. 실제 제원·카고 치수/길이/폭 구분·장비 세부 제원·제원 근거를 나머지 규격에 복사하지 않는다. 해당 안내는 현장규격 영역에만 표시한다.
- 저장 키·버전·기존 ID·기존 이관 규칙·03-3 구현은 변경하지 않았다. 기존 미확인 필드 및 원문 보존 회귀도 통과했다.

## 남은 한계와 범위

- 실제 제원 입력 영역은 기존처럼 한 세트이다. 여러 규격에 서로 다른 제원을 한 화면에서 입력하는 기능은 추가하지 않았다. 기준 규격 외 기록의 제원은 저장 후 각 기록에서 입력해야 한다. 경력·옵션·제조사·모델 등 기존 공통 입력은 계속 공통 적용한다.
- 동일 규격의 여러 실물을 식별하는 별도 일련번호·수량 관리 기능은 이번 범위가 아니다. 동일 제조사·모델·연식의 동일 규격은 일괄 생성 시 중복에서 제외하고, 기존 개별 추가 흐름을 유지한다.
- 서버·DB 코드는 변경하지 않았다. 별도 폐기용 DB가 필요한 전체 서버 통합 테스트는 실행하지 않았으며, 이번 검증의 데이터 범위는 브라우저 로컬 저장·기존 이관·03-3 연동이다.
- GitHub push/merge 및 운영 배포는 수행하지 않았다.
