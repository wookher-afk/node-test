# NODE 0.1 — 확정 요구사항 기준서
상태: 설계 기준선 초안 / 구현은 단계별 진행. 이 문서는 확정된 정책을 추적하며, 상세 필드 및 운영 파라미터는 별도 검토 대상이다.

## 상위 원칙
- UX-001: 내부 복잡성은 NODE가 처리하며 사용자에게는 필요한 결정만 노출한다.
- 일의 기록 = 신뢰. 신고/미응답/분쟁 제기 자체를 자동 불이익으로 취급하지 않는다. 신고 접수만을 근거로 한 징계·신뢰 감점·제3자 매칭 제한 등 확정적 불이익은 금지하되, B8-57·59의 당사자 간 임시 보호조치는 별도로 허용한다.
- 매칭 확정은 양측의 동일 조건 승인; 계약 서명, 작업 완료, 지급 완료는 별도 상태.
- 공개 저장소에 실명, 연락처, 계좌번호, 신분증, 비밀키, 실제 개인정보를 저장하지 않는다.

- DB-004 업체 관리자의 직원 초대, 각자 독립 계정, 복수 업체 소속
- DB-005 업체별 세부 권한, 권한 변경 감사 기록
- DB-006 현장 하나에 직종·장비·단가·기간별 복수 모집 항목
- DB-007 NODE 확정 작업·외부 작업·휴가·개인 일정 통합
- DB-008 기본 근무 요일과 일정/예외를 이용한 가능일 산출; 빈 일정은 자동 가능 판정 아님

- DB-011 기사만/장비+기사/장비만 구분
- DB-012 작업 완료는 작업자·업체 각각 확인, 이견 및 정정 기록
- DB-013 지급자 지급 등록 + 수령자 입금 확인, 부분/지연/분쟁/미확인 구분
- DB-014 신뢰정보는 P-15·16에 따라 작업자 지원 전·업체 선정 전에 제공한다. 통계 항목과 거래 상세 열람을 분리한다. 근무 기록의 열람·직접 제출은 P-36·38을 따르며 상세 권한 구현 방식은 후속 검토한다. 불특정 다수 공개는 확정하지 않는다. 표본수/기간/이의절차를 유지한다.

- EQUIP-009 매칭 후 고장 시 대체 장비 우선 탐색, 신규 당사자 재승인, 실패 시 취소 이력 보존

## LOG 운송 (확정)

- LOG-005 장비 중량/치수와 차량 적재능력/규격 사전 비교, 최종 운송업자 확인
- LOG-006 사고/지연 신고, 당사자 알림, 필요 시 대체 운송 재매칭 및 새 조건 승인

## JOB 구인 (확정)
- JOB-002 직종별 정원형 모집, 날짜별 잔여 정원 자동 계산
- JOB-003 신호수·보조인력 등 복수 직종 등록; 직종별 경력·자격·교육 구분, 직종 코드 확장
- JOB-004 동일 날짜 복수 지원 가능, 매칭 확정 시 겹치는 다른 지원의 확정 차단; 지원 이력 유지
- JOB-005 작업자 지원 및 업체 직접 제안 양방향, 연락처 비동의 공개 금지
- JOB-006 업체의 작업자 검색 기본 종합 적합도순, 거리·경력 등 정렬 가능
- JOB-007 작업자의 공고 검색 기본 맞춤 적합도순, 최신·거리·단가 정렬 가능
- JOB-008 부분 일정 지원 가능, 업체가 부분 지원 허용 여부 지정, 날짜별 정원
- JOB-009 모집 인원 증감 허용. P-03·B8-30에 따라 감원은 미충원 인원·신규 자동매칭 제안에 우선 반영한다. 모집 인원 변경만으로 확정 계약을 자동 취소하지 않는다. 확정 인원보다 정원을 줄이려면 별도 계약 취소 절차와 기존 귀책·보상 정책을 적용한다. 변경·취소·보상 이력을 보존한다. 현재 DB의 확정 인원 이하 축소 차단은 유지하며 후속 구현·검증은 별도다.
- JOB-010 전체 공개/지정 작업자 공개/비공개 직접 제안
- JOB-011 정원·지원 마감·작업일 경과 시 자동 마감, 조기 마감/재공고, 부분일정 예외
- JOB-012 선정/대기/미선정/철회 구분, 결원 시 대기자 재제안 및 재승인
- JOB-013 긴급 구인 적합자 우선 알림, 수신 동의 및 미응답 무감점
- JOB-014 긴급 알림 근거리 우선, 미충원 시 최대 허용범위 내 단계적 확대
- JOB-015 긴급 제안 응답 기한 및 자동 만료, 재제안, 미응답 무감점
- JOB-016 공고 조건 변경 이력/기존 지원자 알림, 확정 매칭 변경 시 재승인
- JOB-017 확정 전 작업자 자유 지원 철회, 확정 후 DB-010
- JOB-018 확정 전 업체 자유 제안 철회, 확정 후 DB-010
- JOB-019 거래 이력 기반 재고용·즐겨찾기, 새 일정·조건 재확인
- JOB-020 작업자·업체 상호 차단, 비공개, 기존 계약/지급 기록 보존, 자동 감점 없음
- JOB-021 양측 신고·증빙·관리자 검토·소명·처리·이의신청. 접수만으로 징계·신뢰 감점·제3자 매칭 제한 등 확정적 불이익을 주지 않는다. B8-57·59에 따라 신고 당사자 사이에서만 신규 매칭 차단·미확정 지원 및 제안 중지를 임시 보호조치로 허용하며 제3자와의 정상 구직·구인은 유지한다. 처리 종료 후 B8-58의 해제 기준을 적용한다.

## 근무 기록 (확정 정책, 구현은 후속)

- WRK-003 P-26~30에 따라 날짜별 근무 완료는 양측이 확인한다. 출퇴근과 실제 작업시간을 구분하고 시간 입력은 선택사항이며 일치한 작업시간만 확정한다. 다중 날짜 일괄 입력·확인을 지원한다. 미응답은 자동 승인 없이 확인 대기로 유지하고 재알림한다.
- 작업자 본인과 해당 현장의 확인 권한이 있는 업체 담당자가 확인하며 권한 없는 직원의 확정·변경을 금지한다. 확인·변경자와 처리 시각, 담당자 변경 전후 기존 이력을 보존한다.
- GPS 위치 추적·위치 기반 출퇴근 인증은 제외한다. 향후 초과근무·급여 정산 기초자료 활용은 P-27을 따르며 급여 정산 기능 구현 완료를 뜻하지 않는다.
