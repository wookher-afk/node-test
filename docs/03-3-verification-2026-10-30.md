## 구현 결과

- 면허/국가기술자격/교육/기타 독립 복수 등록, 수정·삭제·취소, 4단계(각 2~3질문), 큰글씨, 초안·단계·유형별 입력 복원.
- 본인 신고·미확인 / 본인 비공개 / 법정 적합성 미평가. 날짜의 미응답·모름·기재된 만료일·만료일 기재 없음을 구분한다. 입력 만료일 경과는 경고하고 영구 유효로 해석하지 않는다. 기관은 선택이다.
- 명시적 임시저장과 목록 저장. 목록 저장/초안만 보관/계속 작성의 이동 선택. 목록 0건 미응답은 검토 완료를 막고 나중에/보유 없음 응답을 요구한다. 나중에 보완은 기존 목록을 유지한다. 마지막 삭제는 미응답이다.
- 별도 전용 키만 쓰며 Web Locks 배타 잠금 안에서 전체 원문 비교·revision 증가·단일 쓰기·읽기검증을 수행한다. 충돌/저장 실패는 입력과 기존 목록을 유지하고 성공·이동을 중단한다. 현재 입력/원문 내보내기와 명시적 재불러오기 제공.
- 03-2 신키 부재만 구키 폴백. ability의 굴착기/지게차 기록만 추천 근거로 사용하며 추천은 폼만 연다. 보유장비·기사 제공·장비 초안·규격 호칭으로 자격을 판정하지 않는다. 변경된 과거 장비 연결은 보존·안내한다.
- 이전 licenses는 명시적 찾기와 유형 확인 후 목록 저장으로 반영한다. 원 항목 전체(verified 포함)를 legacy.raw에 보존하고 검증 승격하지 않는다. canonical SHA-256 + 동일 원문 출현 회차로 순서 변경·키를 넘는 중복을 방지한다. 삭제 후에도 지문은 중복 방지용으로 유지한다.
- 03-2 기존 다음 검토 동작을 보존하고 검토 영역에 실제 03-3 링크를 추가했다. 기술작업자 별도 링크는 장비/기사 유형 등록을 강제하지 않는다. 03-3에서 03-2로 복귀 가능. 다음 화면은 없어 검토 완료만 표시한다.
- 번호·증빙·검증 요청·서버·법정 규칙표·매칭 엔진은 구현하지 않았다. 법정 요건 작업의 자동/수동 확정 보류 정책은 UI 안내에만 반영했다.

브라우저 테스트는 새 격리 context와 가상 자료/요청 라우팅을 사용했다. 실제 사용자 Chrome 프로필·등록 데이터·초안·DB에는 접근하지 않았다. 03-3에서 기존 키 쓰기/삭제가 없음을 코드와 가상 저장값 전후 비교로 확인했다. 03-2 저장 로직은 그대로이며 app.js는 이동 검토 안내 문자열 1곳만 변경했다.

재현: Node 22와 Playwright/Chrome 환경에서 `node --test tests/ui/03-3-model.test.mjs`, `node tests/ui/03-3.test.cjs`. 필요 시 NODE_BROWSER_MODULE에 Playwright 경로를 지정한다. 기존 테스트 6종은 `node --test tests/ui/03-2*.test.cjs`, NODE_BROWSER_PATH는 Chrome 실행 파일, NODE_UI_OFFLINE=1로 지정하면 기본 테스트도 가상 자료로 실행한다. 서버·DB 테스트는 변경 범위에 없어 실행하지 않았다.

## 보류·한계

실물 모바일 기기, Safari/Firefox, 스크린리더의 수동 검수는 하지 않았다. Web Locks 미지원 브라우저는 보수적으로 저장을 막는다. 로컬 자료는 계정 귀속·기기 동기화·서버 백업이 아니다. 구키에 손상/미지 구조가 있으면 자동 복구하지 않는다.

희망 근무 조건 화면, 기술 프로필의 공통 이전 URL, DB/계정 소유권, 증빙/검증 체계, 기종·톤수별 법정 매핑, 교육 주기, 공개·보관·파기·실제 매칭 게이트는 후속 범위다. 이 구현을 법정 요건 확인이나 실서비스 매칭 준비 완료로 보지 않는다.
