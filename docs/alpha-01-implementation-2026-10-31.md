## 실행 및 후속 작업

1. 프로젝트가 요구하는 Node 22 환경에서 `npm ci`로 잠금 파일 기준 의존성을 설치한다. 이번 환경의 번들 Node는 24.22.1이었다. `pg`는 별도 작업공간에만 설치했으며 package-lock은 변경하지 않았다.
2. 별도 빈 개발 DB에는 기존 001~007 다음에 008을 적용한다. 기존 DB에는 008만 추가한다. 자동 마이그레이션이나 운영 DB 적용은 하지 않았다.
3. 기존 인증 서버용 DB 역할에 새 테이블 `SELECT, INSERT, UPDATE` 권한이 필요하다. PUBLIC 권한은 부여하지 않는다. 로컬 테스트·개발 역할의 권한 추가는 구현했다.
4. 기존 안전장치를 갖춘 `NODE_TEST_DATABASE=1 DATABASE_URL=postgresql://.../node_test npm test`로 전체 테스트를 실행한다. 이 명령은 해당 테스트 DB만 초기화하므로 별도 테스트 DB를 사용한다.
5. `npm run dev:local`로 실행한 후 로그인 → 알파 등록 → 로그아웃 → 재로그인 복원을 실제 DB에서 확인한다.
6. 다음 개발은 업체 모집조건 연결과 등록 문서에서 후속 엔진 입력으로의 명시적 변환이다. 가능 날짜가 예약 확정이나 충돌 검사를 의미하지 않는다.
