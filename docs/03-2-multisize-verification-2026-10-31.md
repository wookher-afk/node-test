## 저장 및 화면 원칙
기존 화면 배치·항목 순서·입력 기능과 단일 문자열 size 저장 구조를 유지한다. 선택 규격마다 별도 UUID 레코드를 만든다. 수정 시 첫 레코드에 기존 ID를 유지하고 추가 선택에만 새 ID를 부여한다. 복수 선택 배열은 초안에만 보관한다. 경력·옵션·실제 제원·제조사·모델은 공통 적용되며 저장 후 개별 수정할 수 있다고 화면에 안내한다. 보유 장비도 실물별 레코드를 유지한다. 카탈로그 규격 내용은 추가·추정하지 않았다.

## 잔여 위험·제한
- 실제 서버 저장·자동매칭은 기존과 동일하게 미연결이며 브라우저 저장 범위다.
- 일괄 입력의 공통 제원이 각 규격/실물에 맞는지는 사용자가 확인해야 한다. 저장 후 개별 수정 가능하다.
- 기존에 중복 등록된 면허는 자동 삭제·병합하지 않는다. 이번 장비별 등록 경로는 기존 면허 수정으로 연결한다. 별도 직접 면허 등록 기능은 유지한다.
- 카탈로그의 기존 누락 규격과 법정 면허 적합성을 새로 검증하거나 확장하지 않았다.
