# 장비 분류 순차 표시 검증 — 2026-10-31

브랜치: feature/node-alpha-01-worker. 기존 미커밋 작업 위에서 필요한 부분만 수정했으며 리셋·체크아웃·푸시·배포·병합은 하지 않았다.

- 첫 진입은 대분류만 노출한다. 대분류 → 중분류 → 소분류 순서로 해당 후보를 표시한다.
- 소분류 선택 후 장비 형태를 표시하고, 형태 선택 후 해당 현장규격을 표시한다. 기존 장비 형태 및 5단 분류 데이터 구조를 유지한다.
- 옵션은 현장규격 선택 후 표시한다. 실제 제원 입력형 장비는 해당 규격 입력 단계에서 선택 가능한 옵션을 표시한다.
- 상위 분류 변경 시 하위 선택을 초기화한다. 형태 변경 시 현장 호칭·직접 입력·옵션 선택을 초기화한다. 이전 장비 입력 원문은 기존 초안 보관 구조에 유지하되 재선택만으로 자동 적용하지 않는다.
- 개발 안내와 반복 안내는 기본 숨김 처리하고 저장 원문 도구는 접힌 영역으로 유지한다. 필수 라벨, 오류·복구 메시지, 저장 상태는 유지한다.
- 저장 키, 레코드 구조, 서버와 DB 코드는 이번 수정에서 변경하지 않았다.
