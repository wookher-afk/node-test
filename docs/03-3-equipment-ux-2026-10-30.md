기존 미커밋 03-3 독립 등록 구현과 별도 03-2 진입 수정이 작업 폴더에 존재하는 것을 먼저 확인했다. 03-2의 다음/계속 버튼이 저장 성공 후 실제 ../03-3/로 이동하는 수정, 초안 확인·저장 실패 차단, 기술작업자 경로와 기존 테스트 수정을 보존했다. 이번 작업에서는 03-2 파일을 추가 수정하지 않았다.

## 변경

- 첫 등록 영역을 ‘등록 장비별 관련 면허’로 배치. 신키 부재 때만 구키 폴백하며 모든 mode=ability 저장 항목을 개별 표시한다. 장비 초안·owned·기사 유형은 보유 판단에 사용하지 않는다.
- 03-2 공통 장비 카탈로그로 이름 표시, 기타 실제 이름·별칭·형태·규격 제공. DOM textContent 사용으로 사용자 입력을 안전하게 표시한다.
- 명시적으로 연결된 license 기록이 없으면 ‘면허 미등록’, 있으면 ‘본인 신고·미확인’. 자격·교육만 연결돼도 면허 보유로 표시하지 않는다. 구 기록은 ‘이전 입력·미확인’, 입력 만료일 경과는 별도 확인 필요 표시.
- 기종·톤수별 공식 법정 매핑이 구현돼 있지 않으므로 모든 장비에 ‘관련 면허 확인 필요’와 직접 선택/입력 버튼 제공. 특정 카탈로그 항목을 추천하거나 미리 선택하지 않는다. 기존 일반 카탈로그는 직접 선택용으로 유지한다.
- 버튼은 해당 장비 ID만 연결한 새 면허 입력을 연다. 저장·검증 승격은 하지 않는다. 기존 독립 면허/자격/교육/기타 복수 등록을 유지한다.
- storage 이벤트, 페이지 복원, 창 포커스 복귀 시 장비 목록 재조회. 작성 중 폼을 먼저 읽어 입력을 보존한다. 삭제된 장비의 연결 ID·면허 원문은 유지하며 ‘연결 장비 변경됨’ 안내를 제공한다.
- 저장키·스키마·Store 잠금/원문 비교·legacy 이관 로직은 변경하지 않았다.
