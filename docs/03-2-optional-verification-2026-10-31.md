# 장비 선택입력사항 통합 — 2026-10-31

작업 브랜치: feature/node-alpha-01-worker. 기존 미커밋 변경을 보존해 통합했으며 푸시·배포·병합하지 않았다.

## 변경

- 대분류→중분류→소분류→현장규격→운용 가능 옵션의 순차 노출 유지. 장비 형태와 기타 장비명·직접 규격은 해당 분류를 완성하는 기존 입력으로 유지.
- 상위 native details ‘선택입력사항’을 최초 닫힘으로 추가. 현장 통용 명칭, 근거, 개별 안내, 추가 제원, 실제 제원, 제조사 참고, 카고 실제 치수, 기타 옵션, 경력 및 보유 상세를 내부로 이동.
- 기존 개별 접기 기능과 필드 ID 및 저장 구조를 유지. DOM을 제거하지 않으므로 접기·펼치기 시 입력값 유지.
- 경력·제조사·모델은 비워도 등록 가능하게 조정. 서버도 빈 경력 문자열만 추가 허용하며 숫자 범위 검증은 유지. 미입력 값을 0으로 변환하지 않음. DB 스키마 변경 없음.
