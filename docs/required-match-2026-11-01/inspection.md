# 필수 일치 체크박스 사전 점검 — 2026-11-01

> 후속 사용자 지시로 체크박스를 제목 왼쪽에 배치했다. 아래는 구현 전의 역사적 점검 기록이며, 현재 결과는 [구현·검증 보고서](implementation.md)를 참조한다.

## 현재 상태

구현 전 공간 부족 보고 단계. 실행 코드, 서버 검증, DB 스키마 및 DB 자료를 변경하지 않았다. 새 파일은 이 점검 폴더의 기준 화면·측정값·재현 스크립트·보고서뿐이다. 기존 미커밋 작업은 그대로 두었으며 커밋·푸시·배포·병합을 하지 않았다.

사용자 지시: “공간이 부족하면 임의 재배치하지 말고 보고.” 모바일에서 제목과 같은 줄에 체크박스를 넣을 공간이 부족하여 배치 예외를 승인받기 전에 구현을 진행하지 않는다. 필수 일치 기능은 아직 구현되지 않았다.

## 확인 방법과 한계

로컬 http://127.0.0.1:8048 의 현재 HTML/CSS/JS를 실제 Chrome에서 390×900, 1440×900 뷰포트로 열고 전체 화면 및 DOM 좌표를 기록했다. 신규 브라우저 컨텍스트에서 API 응답만 가상 로그인/빈 등록 자료로 대체했다. 업체 화면은 점검용 기본정보를 입력하고 기존 다음 버튼을 이용해 모집조건 단계에 진입했다. 저장은 실행하지 않았으며 실제 계정과 DB에 연결되는 API 요청은 차단했다. 장비작업자의 내부 장비 화면은 기존 iframe을 그대로 표시했다. 실제 기기 검증이나 로그인·저장 기능 검증 결과가 아니다.

점검한 화면:
- 업체: /company-registration
- 장비작업자: /worker-registration
- 기술 및 일반작업자: /register/technical

## 공간 부족 근거

현재 기본 글자 크기 16px에서 제목의 같은 줄 우측 여백(제목 컨테이너 폭 - 제목 텍스트 폭):

| 항목 | 390px 여백 | 1440px 여백 |
| --- | ---: | ---: |
| 업체 제시 급여 (만원) | 50.98px | 217.98px |
| 업체 해당 직종·장비 최소 경력 (개월, 무관은 0) | 57.03px | 391.03px |
| 작업자 희망 최소 급여 (만원) | 32.11px | 319.11px |

16px 글자 크기의 ‘필수 일치’ 텍스트와 체크박스, 두 요소 사이 간격을 포함하면 이 모바일 여백 안에 안정적으로 들어가지 않는다. 현재 제목 옆에 일반적인 인라인 체크박스를 추가하면 제목/체크박스가 줄바꿈되거나 입력 시작 위치가 바뀐다. 글자 축소, 제목 생략, 입력 폭 축소, 다른 항목 옆으로 이동, 입력 위 겹치기는 적용하지 않았다.

## 사용자 검토를 위한 구체적인 배치 예외안

공간이 충분한 항목은 제목과 같은 줄에 ‘□ 필수 일치’를 추가한다. 공간이 부족한 모바일 항목만 제목 바로 아래, 기존 입력 바로 위에 체크박스 한 줄을 둔다. 원래 제목·항목 순서·입력 폭·기존 선택 기능은 유지되지만 해당 항목의 세로 높이와 뒤따르는 항목 위치가 늘어난다. 이는 현재의 간격/위치 유지 제약에 대한 예외이므로 아직 적용하지 않았다. 선택 수는 업체 모집 그룹 제목과 작업자 프로필 제목 옆의 여유 공간에 표시하는 방안을 검토할 수 있다.

배치 예외를 허용하지 않는 경우, 어떤 기존 제목을 줄이거나 어떤 다른 위치에 표시할지 별도 지정이 필요하다. 임의로 정하지 않는다.

## 확인된 저장 구조와 후속 구현 범위

- 업체: company_alpha_registrations.document.lines의 모집 그룹 단위 조건. 기존 그룹 ID, 직종 AND(all_per_person), 인원 및 공통 조건을 보존해야 한다.
- 작업자: worker_alpha_registrations.document에 장비 등록과 technicalRegistration이 공존한다. 작업자 필수 조건을 유형별로 각각 3개씩 중복 허용하지 않도록 프로필 범위를 명시하고 서버에서 총수를 검증해야 한다.
- 여러 직종은 작업능력 조건 1개로 계산한다. 기존 직종 체크박스의 선택 수와 필수 조건 수를 구분해야 한다.
- 허용 키, 중복/알 수 없는 키/4개 이상 거부, 0~3개 선택, 3개 도달 시 미선택 비활성화와 선택 해제, 저장·수정·재로그인 복원을 함께 구현/검증해야 한다.
- 법정 면허·자격요건은 사용자 선택 필수 조건 배열에 포함하지 않는다. 기존 자격 입력 및 03-3 관련 자료를 보존하고, 법정 요건 검증 엔진의 구현 여부와 사용자 정책 저장을 구별해야 한다.
- 자동매칭 완료를 주장하지 않는다. 이번 요청의 자동매칭 범위는 향후 양측 필수 조건을 모두 만족하는 정책/자료로 제한한다.
