# 03-3 면허·자격 등록

로컬 미리보기: `http://127.0.0.1:8033/ui/03-3/` (저장소 루트 정적 서버).
03-2는 `../03-2/`. 같은 origin을 사용해야 장비 추천과 기기 저장값이 연결된다. 기존 8032 자료를 새 포트로 자동 복사하지 않는다. 8032 정적 서버에서도 `/ui/03-3/`로 볼 수 있다.

- 독립 면허/국가기술자격/교육/기타 복수 등록, 4단계 입력, 큰글씨, 수정·삭제·초안 복원.
- 목록 저장·임시저장·단계 응답·삭제·검토 완료만 명시적으로 저장한다. `node_03_3_credentials_v1`만 쓴다.
- 03-2 두 키는 읽기 전용. 신키 부재일 때만 구키를 읽고 모든 ability 기록을 장비별로 표시하고 관련 면허 직접 등록을 제공한다. 보유·기사 제공·초안은 추천 근거가 아니다.
- 이전 시안은 명시적 찾기/항목 선택/분류 확인/목록 저장 후 반영한다. legacy 원문과 지문을 보존하며 verified를 검증으로 승격하지 않는다.
- 잠금(Web Locks)과 원문 비교로 탭 충돌 시 쓰기를 중지한다. 미지원 브라우저·손상·미래 구조는 쓰지 않는다. 내보내기 후 다시 불러오기로 복구한다.
- 신고는 미확인, 법정 적합성은 미평가. 면허번호는 면허 신규 등록·수정 시 필수다. 기존 번호 없는 기록은 보존하고 보완 안내한다. 업로드·검증요청·서버·자동매칭·가입완료 기능은 없다. 검토 완료까지만 제공한다.
- 카탈로그는 명세 S2~S5의 공식 확인 명칭 5개로 제한한다. 면허의 기종·종별·제한과 교육 과정은 직접 확인해야 하며 톤수 매핑·만료 계산을 하지 않는다. 일반 명칭 1개는 제한면허의 별도 코드가 아니다.

저장 결정: `docs/03-3-storage-decisions-2026-10-30.md`.
검증: `tests/ui/03-3-model.test.mjs`, `tests/ui/03-3.test.cjs`. 브라우저 테스트는 Playwright와 Chrome을 사용하며 전용 격리 context, 가상 origin/자료만 사용한다. 사용자 브라우저 저장소를 읽지 않는다. 기존 03-2 회귀 테스트 6개도 별도 실행한다.
