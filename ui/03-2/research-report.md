# NODE 공통 장비 규격·체급·현장 호칭 조사 보고서

조사 기준일: 2026년 10월 29일

## 1. 조사 결과를 읽는 기준

**장비 전체에 동일한 ‘톤수 선택창’을 적용하면 안 된다.** 같은 ‘5톤’이라도 화물차 적재중량, 크레인 인양능력, 롤러 중량, 스카이차 차대 호칭을 뜻할 수 있다.

따라서 다음 항목을 분리한다.

| 구분 | 의미 | 예시 |
|---|---|---|
| 장비 종류 | 실제 구조·용도 | 휠로더, 러프터레인 크레인, 콤비롤러 |
| 현장 호칭 | 국내 업체·작업자가 사용하는 표현 | 페이로더, 바브캣, 25톤 크레인 |
| 현장 체급 | 배차·견적·검색에 사용하는 구간 | 3루베 이하, 2.5톤 콤비 |
| 제조사 모델 | 제조사가 부여한 식별명 | HL960A, GR-250N, TW354 |
| 공식 제원 | 조건과 단위가 있는 수치 | 버킷용량 ㎥, 하중중심 500㎜에서 적재능력 ㎏ |
| 장착 구성 | 실제 개체의 작업장치·옵션 | 하이리프트, 지브, 드럼, 포크 |
| 운전능력·경력 | 사람이 수행 가능한 범위 | 굴절식 고소작업대 운전, 항타·항발 작업 |

**확실성은 주장별로 판단한다.**

- **A — 공식 확인:** 제조사·공식 국내 공급사 자료에서 해당 모델·사양 확인.
- **B — 국내 사용 확인:** 국내 장비업체의 직접 보유·임대·판매 자료에서 표현 확인. 전국 공통 표준을 뜻하지 않는다.
- **C — 제한적 확인:** 과거 자료, 특정 공법 자료, 간접 자료 또는 단일 사례.
- **보류 — 근거 부족:** 고정 호칭이나 수치 선택지로 채택할 근거가 부족하다.
- **설계 제안:** 조사 결과에 근거한 NODE 구성안이다. 현장 표준이라는 뜻이 아니다.

해외 공식 제원은 **기술적 의미 확인용**이다. 국내 판매·운용 사양이라는 사실까지 자동으로 입증하지 않는다.

## 2. 토공·적재·정지 장비

### 2-1. 불도저

**확인된 명칭·선택 후보**

공식 국내 공급사 혜인은 D1 LGP, D3 LGP, D6 LGP, D8 LGP, D9 LGP, D10, D11을 구분해 소개한다. 따라서 이 명칭은 **제조사 모델 계열 선택지**로 사용할 근거가 있다. 다만 D6를 제조사 공통 체급 코드로 사용하면 안 된다. **A**

공급사 자료에서 D6 LGP 자체중량은 23,530㎏, D8 LGP는 38,085㎏으로 제시된다. **D6의 숫자 6은 6톤을 뜻하지 않는다.** [혜인 불도저 제품 목록](https://catmachine.haein.com/catmachine/product/list_3depth.php?part_idx=5)

**NODE 적용 제안**

- 우선 선택: 제조사·정확한 모델·접미사.
- 별도 제원: 자체중량 또는 운전중량, 엔진출력, 블레이드 폭·용량.
- 주요 구성: LGP 등 하부 구성, 슈 폭, 블레이드 형식, 리퍼, 윈치, 정지 제어장치.
- 전국 공통의 고정 숫자 호칭 목록: **보류**.
- ‘소형·중형·대형’ 구간을 만들 경우 **NODE 검색용 구간**임을 명시한다.

### 2-2. 휠로더

**확인된 명칭·선택 후보**

국내 거래 자료에서 ‘페이로더’, ‘페이로다’, ‘로더’가 사용된다. 거래 플랫폼에는 ‘3루베 이하’, ‘4루베 이하’, ‘6루베 이하’, ‘6루베 이상’처럼 **버킷용량을 기준으로 한 구간**이 나타난다. **B** [국내 페이로더 거래 분류](https://specialists.kr/list/1/48?device=pc&page=2)

반면 현대 공식 HL955A·HL960A 카탈로그에는 버킷 구성별로 서로 다른 용량이 제시된다. 현장 구간명과 장착 버킷의 정확한 용량은 별개다. **A** [현대 공식 HL955A·HL960A 카탈로그](https://www.hyundai-ce.com/resources/KOR_HL955A_HL960A%2823.08%29_web.pdf)

**NODE 적용 제안**

- 주 규격: **현재 장착 버킷용량 ㎥**.
- 현장 호칭: ‘○루베급’을 별도 보존.
- 주요 구성: 일반·암석·경량물 버킷, 하이리프트, 포크, 퀵커플러, 계량장치, 라이드 컨트롤.
- ‘3루베급 = 특정 모델’ 대응: 금지.
- 체급 구간은 중복되지 않도록 정의하되, 이를 전국 현장 표준으로 표시하지 않는다.

### 2-3. 스키드로더·소형 트랙로더

**확인된 명칭·선택 후보**

국내 시공업체가 ‘스키드로더(바브캣)’라는 표현을 직접 사용한다. ‘바브캣’은 검색 별칭으로 유효하지만 제조사 필드와 분리해야 한다. **B** [삼부자중기 작업·임대 안내](https://busajg.co.kr/)

밥캣 한국어 S450 제원자료에는 정격적재용량 ROC 590㎏이 제시된다. **모델명 S450을 적재능력 450㎏으로 해석할 수 없다.** **A** [밥캣 S450 한국어 제원](https://assets.bobcat.com/products/korean_spec_2021/SPEC-S450.pdf)

**NODE 적용 제안**

- 하위 종류: 바퀴식 스키드스티어 / 궤도식 소형 트랙로더.
- 주 규격: 정격적재용량 ROC.
- 보조 제원: 운전중량, 전폭, 버킷용량, 보조유압 유량·압력.
- 주요 구성: 버킷, 브러시, 포크, 브레이커, 오거, 절삭장치, 고유량 유압, 타이어·트랙.
- 어태치먼트 보유와 해당 작업 운전경력은 별도 등록한다.

### 2-4. 그레이더

대한건설협회 공개 자료에서 모터그레이더 규격 3.6m를 확인할 수 있으며, 규격은 **삽의 폭**이라고 설명한다. 이는 국내 적산 규격 근거다. **A — 적산 기준 / 현장 통용성은 별도** [대한건설협회 규격 설명](https://www.cak.or.kr/download.do?uuid=4d82303b-2108-488f-bd0a-a4bfb214ddde.pdf)

혜인은 국내에 120GC 모델을 소개한다. 따라서 모델명과 블레이드 폭을 분리할 근거가 있다. **A** [혜인 120GC 국내 소개](https://www.catmachine.kr/media/?code=news&idx=153&mode=v)

- 주 규격: 블레이드 폭 m.
- 모델 선택: 정확한 제조사 모델.
- 주요 구성: 리퍼·스캐리파이어, 전륜구동 여부, 자동 정지 제어, 블레이드 연장 구성.
- ‘140 = 14톤’ 같은 모델명 해석은 금지.
- 3.6m 외 전국 공통 현장 체급 목록은 추가 검증 전 보류한다.

### 2-5. 스크레이퍼

제조사 공식 Cat 623 자료는 산적용량 17.6㎥와 평적용량 14.4㎥를 별도로 제시한다. **같은 장비에서도 용량의 측정 기준이 다르다.** **A** [Cat 623 공식 제원](https://www.cat.com/en_US/products/new/equipment/wheel-tractor-scrapers/elevating-scrapers/125871.html)

- 하위 종류: 자주식 / 피견인식.
- 주 규격: 보울 용량 ㎥, 산적·평적 기준.
- 보조 제원: 정격적재중량, 절삭폭, 동력.
- 주요 구성: 엘리베이팅·오픈보울 등 구조, 푸시풀 장치.
- 623 같은 모델 번호를 용량이나 톤수로 환산하지 않는다.
- 국내 현장 고정 호칭 목록은 **보류**. 해외 제품 라인업을 국내 보급 목록으로 사용하지 않는다.

## 3. 천공·기초 장비

### 3-1. 천공기

국내 건설기계 소음 연구자료에는 수산 STD11·STD11E, 전진 JD-800 계열, 에버다임 ECD35·ECD40 등이 나타난다. 이는 **국내 조사 대상 모델의 존재 근거**이며 현재 판매 또는 전체 작업능력의 증거는 아니다. **C** [건설기계 소음관리 연구자료](https://www.codil.or.kr/filebank/original/RK/OTKCRK230693/OTKCRK230693.pdf)

수산 공식 사이트는 유압드릴을 별도 제품군으로 제공한다. **A — 제품군 확인** [수산세보틱스 공식 제품 안내](https://soosancebotics.com/ko/main)

**NODE 적용 제안**

천공기는 ‘몇 톤’보다 다음 순서로 선택하는 편이 적합하다.

1. 작업 용도: 노천 발파 / 터널 / 앵커·보강 / 기타.
2. 천공 방식: 톱해머 / DTH / 회전식 등.
3. 천공경 ㎜ 및 깊이 m.
4. 제조사·모델·연식·장착 드릴 구성.

주요 구성은 집진, 습식 분진 억제, 로드 취급장치, 깊이·각도 표시, 원격조작, 외부 압축공기 요구조건이다.

‘크롤러드릴’, ‘유압드릴’, ‘천공기’를 완전한 동의어로 합치거나, 모델 번호를 천공경으로 해석하지 않는다. **천공경 숫자 목록은 국내 모델별 공식 제원 확보 후 확정한다.**

### 3-2. 항타·항발기

국내 기초공사업체가 DH608-120M을 보유 장비로 소개한다. **B** [청오기초건설 장비 소개](https://www.cheongoh.net/blank-1)

일본차량 공식 자료에서도 DH608-120M과 장착 오거·공법 구성의 구분을 확인할 수 있다. **A** 또한 국내 연구자료에는 DH508·DH608·DH658·DH758 같은 모델 계열이 공법별 장비 검토에 사용된다. **C** [국내 말뚝 시공 검토자료](https://www.codil.or.kr/filebank/original/RK/OTKCRK170408/OTKCRK170408.pdf)

**NODE 적용 제안**

- 작업 구분: 항타 / 항발 / 천공·매입 / 압입 등.
- 본체 모델과 작업장치를 분리.
- 핵심 제원: 리더 길이, 적용 말뚝·케이싱 직경, 오거 출력·토크, 해머 사양.
- 주요 구성: 드롭·유압·진동해머, 오거, 케이싱 장치, 압입 장치, 보조 윈치.

**DH608 = 60톤급** 또는 **해머 6톤 = 본체 6톤**으로 저장하면 안 된다. 특정 연구의 모델별 시공 조건을 일반적인 능력 보증표로 사용하지 않는다.

WIRTGEN W 200 Fi 공식 자료에는 **1.5m·2.0m·2.2m 드럼 구성**이 제시된다. **모델명이 같아도 실제 절삭폭이 다르다.** **A** [WIRTGEN W 200 Fi 공식 자료](https://www.wirtgen-group.com/binary/full/o229549v77_W200Fi_Brochure_Datasheet_enGB.pdf)

- 주 규격: 현재 장착 드럼 절삭폭.
- 보조 제원: 절삭깊이, 운전중량, 비트 간격.
- 주요 구성: 표준·미세절삭 드럼, 컨베이어, 레벨 제어, 집진·살수.
- ‘파쇄기’ 같은 표현은 용도가 모호하므로 자동 동의어 처리하지 않는다.
- 국내 공통 ‘0.5·1·2m급’ 전체 목록은 이번 조사만으로 확정하지 않는다.

## 8. 발전·압축공기 장비

### 8-1. 발전기

국내 임대업체는 **30~50, 50~75, 100~150, 150~250kW** 등의 용량 구간을 직접 사용한다. 이는 국내 임대 분류 사례다. **B** [신명발전기 임대 분류](https://smgenerator.com/)

Denyo DCA-60USIB3 공식 자료는 50/60Hz에서 **50/60kVA**, 삼상 역률 0.8을 제시한다. **모델명 60을 60kW로 저장하면 안 된다.** **A** [Denyo 공식 제원](https://www.denyo.co.jp/products/dca-60usib3/)

**NODE 선택 구조**

- 정격 유효전력 kW.
- 정격 피상전력 kVA.
- 정격 종류: 연속·상용·비상 등 제조사 기준.
- 주파수, 전압, 단상·삼상.
- 주요 구성: 방음형, 연료탱크, 병렬운전, 자동절체, 분전·케이블 구성.

kVA→kW 환산은 해당 사양의 역률을 확인한 경우에만 계산값으로 표시한다. 일본 공식 전압 사양을 국내 380V 사양으로 자동 치환하지 않는다.

### 8-2. 콤프레서·공기압축기

AIRMAN 공식 자료에서 PDS265S·PDS390S·PDS670S·PDS750S의 토출공기량과 압력이 구분된다. 예를 들어 해당 자료의 PDS390S는 **11.0㎥/min·0.69MPa**다. **A — 해당 접미사·세대 사양** [AIRMAN 공식 PDS 카탈로그](https://www.airman.co.jp/media/files/2203_SOGO_36P_no22.pdf)

**NODE 선택 구조**

- 종류: 엔진 이동식 / 전동식 등.
- 주 규격: 토출공기량 ㎥/min와 정격 토출압력.
- 보조 제원: 동력, 크기·중량, 연결구 구성.
- 주요 구성: 애프터쿨러, 드라이어, 필터, 방음, 트레일러·박스형.
- 별칭: 콤프레샤·콤프레셔·콤프레서 검색 지원.
- ‘390’을 390마력, 390L 탱크, 모든 제품 공통 유량으로 해석하지 않는다.
- ‘390급’의 전국 공통 현장 체급화는 추가 검증 전 보류한다.

## 9. ‘등’에 해당하는 추가 장비의 처리

이번 요청에 명시된 장비는 모두 위에 포함했다. 다만 이전 대화에서 **기존 장비 분류표 전체 원본이 확인되지는 않았으므로**, 아래 장비를 기존 확정 분류라고 간주하지 않는다.

향후 누락 점검 대상은 콘크리트 펌프·펌프카, 정치식 믹서, 아스팔트 살포기, 노면청소·스위퍼, 래머·플레이트 콤팩터, 양수·배수펌프, 지반개량·안정처리 장비, 파쇄·선별 장비 등이다.

이들은 각각 다음과 같은 독립 규격이 필요하다.

| 장비 | 규격 설계에 필요한 축 |
|---|---|
| 콘크리트 펌프카 | 수직·수평 도달거리, 토출량·압력, 붐 구성 |
| 정치식 믹서 | 1회 배출량, 혼합방식, 동력 |
| 아스팔트 살포기 | 탱크용량, 살포폭, 살포 제어 |
| 스위퍼 | 청소폭, 호퍼용량, 흡입·브러시 구성 |
| 래머·플레이트 | 기계중량, 기진력·충격 특성, 작업폭 |
| 양수·배수펌프 | 유량, 양정, 구경, 고형물 통과능력 |
| 파쇄·선별 장비 | 처리량, 투입·배출 규격, 파쇄·스크린 구성 |

이 표는 **분류 확장 검토안**이며, 국내 통용 숫자 선택지 조사 완료표가 아니다.

## 10. NODE 공통 선택 체계 제안

### 10-1. 공통 입력 구조

기존 대·중·소분류와 등록 기능은 유지하고, 장비마다 다른 규격 축을 연결하는 방식을 제안한다.

| 항목 | 보존할 내용 |
|---|---|
| 등록 대상 | 운전 가능 장비 / 실제 보유 장비 |
| 장비 분류 | 기존 분류 식별자와 명칭 |
| 하위 구조 | 바퀴·궤도, RT·AT, 시저·붐 등 |
| 현장 호칭 | 사용자가 선택·입력한 원래 표현 |
| 현장 체급 | 수치·단위·범위와 적용 지역·출처 |
| 제조사 모델 | 제조사, 모델, 접미사, 연식·세대 |
| 공식 제원 | 수치, 단위, 측정 기준, 적용 조건 |
| 실제 장착 구성 | 버킷·드럼·붐·마스트·작업장치 |
| 옵션 상태 | 보유 / 장착 / 장착 가능 / 미확인 |
| 근거 | 공식자료·국내 사용자료·사용자 입력 |
| 검증 상태 | 확인 / 잠정 / 충돌 / 미확인 |
| 경력 | 장비·체급·작업장치별 경험 범위 |

운전능력 등록은 모델을 모르는 경우에도 진행할 수 있어야 한다. 반면 보유 장비는 정확한 모델과 실제 장착 구성을 점차 보완할 수 있게 한다.

### 10-2. 장비별 대표 규격 축

| 대표 축 | 장비 |
|---|---|
| 중량 + 모델·구조 | 불도저, 롤러 |
| 버킷·보울 용량 | 휠로더, 스크레이퍼 |
| 정격적재능력 + 조건 | 스키드로더, 지게차 |
| 폭 | 그레이더, 피니셔, 도로절삭기 |
| 천공경·깊이 + 방식 | 천공기 |
| 공법·본체·작업장치 | 항타항발기 |
| 적재중량 + 적재部 치수 | 덤프, 카고, 트레일러 |
| 탱크・혼합 용량 | 살수차, 믹서트럭 |
| 인양능력 + 작업반경 | 크레인, 타워크레인、카고크레인 |
| 높이 + 도달거리・정격하중 | 고소작업대, 스카이차 |
| 높이 + 운반하중・설치条件 | 사다리차 |
| 정격하중 + 케이지・속도 | 건설용 리프트 |
| kW・kVA + 전원 조건 | 발전기 |
| 유량 + 압력 | 콤프레서 |

### 10-3. 선택지의 표시 원칙

선택 항목마다 다음 중 무엇인지 구분한다.

- **현장 호칭:** 국내 사용 근거가 있는 표현.
- **정확한 제원:** 조건이 확인된 제조사 수치.
- **NODE 검색 구간:** 서비스가 편의상 정의한 범위.
- **직접 입력:** 검증 전 사용자 표현.

예를 들어 ‘3루베급’과 ‘버킷 3.3㎥’는 동시에 저장할 수 있다. 전자를 선택했다고 후자를 자동으로 확정하지 않는다.

### 10-4. 굴착기 조사 오류를 반복하지 않는 규칙

1. **55=03W, 140=06W 대응은 채택하지 않는다.**
2. 숫자 모델명에서 중량·용량·현장 체급을 추정하지 않는다.
3. 제조사·모델·접미사·세대가 확인되기 전 자동 대응을 만들지 않는다.
4. 현장 호칭과 공식 제원은 서로 다른 근거로 검증한다.
5. 검색 별칭 관계와 동등 체급 관계를 구분한다.
6. 사양이 충돌하면 값을 평균 내거나 임의 선택하지 않고 적용 조건을 확인한다.
7. 원문 표현은 보존하고, 표준화 값은 별도 관리한다.
8. 미확인 값은 ‘기타·직접 입력·모름’으로 남길 수 있게 한다.

## 11. 적용 판단

**현재 근거로 채택 검토가 가능한 것**

- 장비별 규격 단위를 다르게 사용하는 구조.
- 제조사 모델과 현장 호칭의 분리.
- 크레인 톤수, 로더 루베, 콤비롤러 체급 등 확인된 국내 사용 표현의 수집.
- 모델·접미사·장착 구성에 종속된 공식 제원.
- 주요 옵션의 보유·장착·운전경력 분리.

**추가 검증 전 확정하지 않을 것**

- 모든 장비를 망라하는 전국 공통 숫자 체급표.
- 모델 번호와 현장 체급의 일대일 대응표.
- 지역·업체별 호칭을 전국 표준으로 승격한 목록.
- 과거 적산 규격을 현재 임대시장 전체 목록으로 사용하는 방식.
- 해외·수출용·다른 인증 사양을 국내 장비와 동일시한 값.

**이번 보고서는 요청된 장비 전 범주를 검토했지만, 모든 범주의 국내 통용 숫자 목록이 검증 완료된 것은 아니다.** 근거가 부족한 항목은 보류로 남겼다. 03-2 v0.1의 구성과 기능은 유지하며, 이 보고서는 이후 규격 목록을 보완할 때 사용할 조사 근거로 한정한다.
