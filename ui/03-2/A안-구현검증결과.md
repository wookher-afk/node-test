## 저장값 호환성

- 기존 `node_03_2_v1`은 쓰거나 지우지 않는다. A안 `node_03_2_a_v1`만 저장한다. version 2 및 aRevision 1을 사용한다.
- A안 키가 있으면 그것만 복원한다. 손상·미지원 버전·접근 실패 시 구 키로 조용히 돌아가지 않고 일반 입력·변경·저장 경로의 쓰기를 차단한다.
- 구 version 1/2의 17개 숫자 ID는 고정 대응표로만 바꾼다. 원문·출처 키를 A안 이관 백업에 함께 보관하고 저장 직후 문자열을 다시 읽어 대조한다.
- records, 최상위 draft, 종류별 초안과 그 중첩 초안을 검사한다. 충돌·키/종류 불일치는 `aSnapshotConflicts`에 원문 보관한다. 임의 합병·삭제하지 않는다.
- 루트·항목의 추가 필드, 개월 경력, 이전 옵션, 초과 제원, 새 aSpecs의 추가 값은 보존한다. 미확인 장비는 원문 읽기만 제공하며 수정·삭제를 막는다. 미확인 최상위 초안은 저장을 보호하고 수동 확인을 요청한다.
- 기존 specs의 순서와 문자열은 유지한다. 믹서 과거 드럼 값에서 새 용량을 추출하지 않는다. 펌프 호칭에서 높이·거리·붐 길이를 만들지 않는다. 빈 값은 0으로 바꾸지 않는다.
- 펌프 라인형은 붐 관련 입력을 화면·카드 성능 표시에서 숨기고 보관 원문에서 접근할 수 있다. 붐형으로 돌아가면 다시 복원된다.
- 이관 뒤 변경은 구 화면에 자동 반영되지 않는다. 롤백 전 A안·구 키 원문을 각각 내보내야 한다. 주소·포트가 달라지면 저장소도 달라진다.
- 실제 사용자 저장소를 테스트하거나 삭제하지 않았다. 별도 브라우저 컨텍스트의 가상 데이터만 사용했다.

## 실행 방법과 범위

테스트는 Node.js와 Playwright 및 로컬 Chrome을 사용한다. A안 테스트는 로컬 파일을 별도 테스트 브라우저의 요청에 직접 응답하므로 운영 서버나 사용자 프로필에 접근하지 않는다.

```sh
NODE_BROWSER_MODULE='<Playwright 설치 경로>' NODE_BROWSER_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' <Node 실행 경로> tests/ui/03-2-a.test.cjs
NODE_UI_OFFLINE=1 NODE_BROWSER_MODULE='<Playwright 설치 경로>' NODE_BROWSER_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' <Node 실행 경로> tests/ui/03-2.test.cjs
```

저장소 장애는 테스트 브라우저 안에서 Storage 읽기/쓰기를 차단하거나 재확인 실패를 발생시킨 모의 시험이다. 실제 디스크를 가득 채우거나 사용자 브라우저 저장소를 손상시키지 않았다. T14의 구 화면 동작은 구 키 불변과 원문 비교로 확인했으며 구버전 브라우저 탭의 동시 편집·합병은 이번 범위 밖이다.

처음 테스트 브라우저 실행 시 실행 환경 제약으로 Chrome 프로세스 9176이 종료되어 macOS 충돌 창이 표시됐다. 사용자에게 이를 설명했고 이후 별도 프로필의 격리 실행으로 검증했다. 원격 작업·배포와 무관하다.

## 남은 위험과 화면 확인

- 실제 사용자 데이터의 임의 확장 구조를 전부 예측하지 않는다. 해석 불가능한 구조는 삭제 대신 저장을 막고 원문 내보내기로 보존한다. 손상 데이터 자동 수선·파일 가져오기·구/신 탭 병합은 구현하지 않았다.
- 브라우저 저장공간은 원문 백업만큼 추가로 필요하다. 저장 실패 시 화면 입력과 양쪽 저장 원문을 각각 내보내고 접근·공간 문제를 해결한 뒤 복원을 재시도해야 한다. 재시도는 페이지를 다시 읽으므로 먼저 화면 입력을 내보내야 한다.
- 외부 출처를 재검증하거나 미확정 숫자를 확정하지 않았다. 근거 문서가 있어도 개별 실물의 제원이 검증됐다는 뜻이 아니다.
- 실제 휴대폰, 다른 브라우저, 실제 배포 환경, 서버/DB는 이번 로컬 검증에 포함하지 않았다.

현재 로컬 서버는 `http://127.0.0.1:8032/ui/03-2/`에서 응답한다. 같은 주소의 기존 탭에서 새로고침하고 이전 화면이 남으면 macOS `⌘⇧R`로 강력 새로고침한다. 브라우저 데이터/사이트 저장소를 삭제하지 않는다. A안이 처음 열리면 구 키를 보존한 채 새 키로 이관하며 이후 A안 변경만 새 키에 기록한다.
