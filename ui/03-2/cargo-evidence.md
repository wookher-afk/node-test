모든 톤급에서 길이·폭 직접 입력과 모름을 허용합니다. 기존 조합은 목록 밖이어도 ‘이전 입력’으로 보관합니다. 표준 길이라는 전역 선택지는 근거 부족으로 만들지 않았습니다.

화면의 모델별 참고 링크는 해당 제조사 문서로 연결됩니다. 봉고(2026.09.01), 마이티(2025.06), 파비스(2026.05), 엑시언트(2026.05), 구쎈·맥쎈(NOV24)의 보고서에 확인된 사양만 사용합니다. 같은 mm라도 다른 사양의 길이·폭을 합치지 않습니다. 미확인 폭은 빈 실제 값으로 유지합니다. 파비스 복합재 2410mm 옵션은 적용 조합 미확정으로 보류합니다.

제조사 출고 예시는 실차·평판·특장 변경 후의 유효 치수가 아닙니다. 숫자를 선택만으로 자동 저장하지 않습니다. 실제 mm 입력과 기존 specs[1]의 m 입력은 각각 원문을 보존하며 서로 덮어쓰거나 자동 환산하지 않습니다. 전폭·축거를 적재함 치수로 전용하지 않습니다.
