## 동작

톤급 → 근거가 있는 길이 호칭 → 해당 길이의 폭 호칭을 제공한다. 일괄 표준/장축/초장축 메뉴를 만들지 않는다. 길이·폭 호칭과 실제 mm는 모름/빈값을 허용하고 직접 입력·수정 가능하다. 이전 조합이 현재 후보에서 벗어나면 ‘이전 입력’으로 보존하고 참고 모델은 매칭하지 않는다. 모델·캡·문서판별 숫자는 링크와 함께 참고로 표시하며 실제 값으로 복사하지 않는다.

일반 적재함·평판·형태 직접 입력, 기존 선택 옵션·등록 필드, specs 배열 및 초과 원문·미래 필드·기존 m 단위 값은 유지한다. 새 `cargo` 객체에 길이/폭 호칭·직접 입력·mm 원문을 저장하며 기존 필드와 자동 환산하거나 덮어쓰지 않는다. 등록 최대적재량을 톤급으로 자동 생성하지 않는다. 브라우저 임시저장 검토 화면 범위이며 서버 등록·자동매칭 기능 추가는 없다.
