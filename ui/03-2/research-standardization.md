**4. 선택값은 어디까지 근거가 있는가**

**모든 장비에 전국 공통의 고정 규격 메뉴가 존재한다고 볼 근거는 확보하지 못했습니다.** 따라서 다음 세 종류를 나눠 제공하는 것이 좋습니다.

| 선택값 종류 | 표시·저장 방식 |
|---|---|
| 제조사 확인값 | 제조사 → 모델 → 구성 선택으로 제원 불러오기 |
| 국내 적산자료의 규격 | ‘적산 참고규격’으로 표시. 시장 전체를 대표하는 법정 등급으로 취급하지 않음 |
| 현장 통용 급수 | 별칭으로 검색 지원. 수치 대응이 검증된 경우만 표준값에 연결 |

대한건설협회가 공개한 **2026년도 건설기계 경비산출표**에서 다음 값들을 확인했습니다. 아래는 선택값 후보의 근거이며, 모든 실제 장비가 이 값에 정확히 들어맞는다는 의미는 아닙니다.

| 장비·형식 | 확인된 참고 선택값 |
|---|---|
| 불도저·무한궤도 | 7·10·12·19·32t |
| 불도저·타이어 | 15·28·33t |
| 굴착기·무한궤도 | 버킷 0.12·0.20·0.40·0.60·0.70·0.80·1.00·1.20·2.00㎥ |
| 굴착기·타이어 | 버킷 0.18·0.60·0.80·1.00㎥ |
| 로더·타이어 | 0.25·0.57·0.95·1.34·1.72·2.29·2.87·3.50·5.00㎥ |
| 그레이더 | 3.6m |
| 믹서트럭 | 6.0㎥ |
| 콘크리트 펌프차 | 21·28·32·36·41·43·47·52m |

출처: [2026년도 건설기계 경비산출표, PDF 4~7·13~14쪽](https://www.cak.or.kr/download.do?uuid=b25d1f7d-c15d-4900-9806-f5f2d26239cf.pdf).

이 자료에서 굴착기는 버킷용량을 사용하지만, 앞서 확인한 행정 규격은 중량을 사용합니다. **이 차이 자체가 규격을 하나의 문자열로 저장하면 안 되는 이유입니다.**

현재 저장소의 `017·020·035·055·080·140·200…` 목록은 그대로 표준 급수로 확정하기 어렵습니다. 모델·중량급 표현과 버킷 기반 현장 호칭이 섞일 가능성을 검토해야 합니다.

- `06W` 같은 명칭의 국내 사용 사례는 공공 건설자료에서도 확인됩니다.
- 그러나 `06W = 특정 중량 = 정확히 특정 버킷용량`이라는 전국 공통 환산은 이번 조사로 확정하지 않습니다.
- `미니`도 단독 규격값으로 쓰지 않고 중량·폭·주행방식을 함께 받습니다.
- ‘10톤 이상’은 검색 범위로 사용할 수 있지만, 실물 장비의 정확한 정격하중을 대신하지 못합니다.

국내 사용 사례: [한국건설기술연구원 CODIL 공개자료](https://www.codil.or.kr/filebank/original/RK/OTKCRK220176/OTKCRK220176.pdf).

**표에 없는 장비의 고정 숫자 메뉴는 미확정**으로 두고, 우선 **모델 선택 + 단위가 정해진 직접 입력 + 확인 필요**를 지원하는 안을 권합니다.

**5. 자격·교육은 규격과 별도 관리**

‘운전 가능’ 체크만으로 법적 자격이 확인된 것으로 표시해서는 안 됩니다. 다음을 분리해야 합니다.

| 대상 | 수집·확인할 내용 |
|---|---|
| 굴착기·불도저·로더·지게차·기중기·그레이더·롤러·피니셔 등 | 해당 기종 조종사면허, 면허 범위, 필요한 교육 |
| 소형건설기계 | 기종별 특례 대상과 제한범위, 교육·면허 발급 상태 |
| 덤프·믹서·펌프카·트럭적재식 천공기 등 | 자동차운전면허 적용과 실제 차량·작업 범위 |
| 카고트럭·살수차·트레일러·견인차 | 차량 종류에 맞는 운전면허와 해당 업무의 추가 요건 |
| 차량탑재형 고소작업대·카고크레인 | 도로 운전과 장치 조종자격을 분리 |
| 타워크레인 | 조종자격·제한범위, 설치·해체 자격·교육을 별도 기록 |
| 리프트·사다리차·발전기 등 | 세부 장비와 작업을 먼저 특정한 후 적용 자격·교육 확인 |

현행 시행규칙 제73조에는 **5t 미만 불도저·로더, 일정한 5t 미만 천공기, 3t 미만 굴착기·지게차·타워크레인** 등의 특례가 규정돼 있습니다. 이는 장비 전체를 소·중·대로 나누는 기준이 아니라 **면허·교육 적용범위의 경계**입니다. [현행 제73조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025745727).

차량탑재형 고소작업대·이동식 크레인 등의 조종자격은 취업제한규칙도 함께 확인해야 합니다. [취업제한규칙](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&efYd=20220218&lsiSeq=240881).

권고 저장항목은 `자격종류 / 적용기종 / 제한범위 / 발급기관 / 취득일 / 유효·확인상태 / 증빙`입니다. **자격증, 조종사면허, 운전면허, 교육수료를 서로 다른 기록**으로 관리합니다.

장비별 최종 자격 대응표, 교육 유효기간 알림, 민감서류 전달 방식은 기존 미확정 정책을 유지하고 이번 제안으로 확정하지 않습니다.

**6. 작업자·업체 공통 분류와 자동매칭 모델**

기존 **대분류 → 중분류 → 소분류 → 규격 → 옵션** 방향은 유지할 수 있습니다. 다만 앞의 세 단계는 찾기 위한 탐색 경로로 사용하고, 실제 매칭은 **장비 종류 코드와 제원**을 기준으로 해야 합니다.

예를 들어 지게차를 ‘운반’과 ‘양중’ 양쪽에서 찾을 수 있어도 동일한 장비 코드를 가리키게 합니다.

| 데이터 | 역할 |
|---|---|
| 장비 종류 | 굴착기·로더·롤러 등 공통 코드 |
| 장비 형태 | 휠·궤도, 붐식·라인식, 시저·굴절붐 등 |
| 규격 정의 | 항목명·단위·평적/산적·정격조건·입력형식 |
| 모델·구성 | 제조사·모델·연식·부착장치별 공식 제원 |
| 현장 별칭 | 06W·스카이 등과 표준 코드의 연결 |
| 실물 장비 | 고유 NODE ID, 등록체계·번호, 소유·관리권한, 실제 구성 |
| 작업자 운전능력 | 기종·형태·규격범위·작업방식·경력·자격 |
| 업체 요구조건 | 동일 제원에 대한 최소·최대·필수·선호 조건 |
| 근거·버전 | 출처, 확인일, 적용기간, 검증상태 |

규격은 예를 들어 다음 정보까지 구분합니다.

- `중량 23t`의 의미가 운전중량인지 운송중량인지.
- `버킷 3㎥`가 평적용량인지 산적용량인지.
- `출력 100kVA`가 상용인지 비상인지.
- `토출량 10㎥/min`이 어느 압력에서의 값인지.

옵션은 기존 확정 정책대로 **설치됨 / 별도 보유 / 사용 불가**를 구분하고, **미확인** 상태도 추가하는 안을 권합니다. 별도 보유 옵션은 해당 작업일에 실제 설치·사용 가능한지도 확인해야 합니다.

매칭 판정은 다음 원칙을 권합니다.

1. **기사만:** 작업자가 업체 제공 장비의 기종·형태·작업방식에 대응하는지 확인.
2. **장비+기사:** 실제 장비 성능과 기사 능력·자격, 양쪽 일정을 함께 확인.
3. **장비만:** 공급 장비의 성능·사용권한·일정과 별도 조종자 배정을 확인.
4. **수치 미확인:** 적합으로 통과시키지 않고 ‘추가 확인 필요’로 표시.
5. **크레인·지게차·고소작업차:** 최대능력 하나가 아니라 요구 반경·높이·하중의 조합으로 비교.
6. **대체 장비:** ‘더 큰 장비’라는 이유만으로 대체하지 않음. 진입폭·중량·지지폭·작업방식을 함께 확인.

제원 확인 부족은 **매칭 적합도 미확인**이며, 작업자의 신뢰가 낮다는 뜻으로 처리하지 않습니다.

기존 확정 요구사항인 소유자·관리자·기사 분리, 장비·기사 이력 분리, 장비별 일정, 동시 가용성, 운송조건, 조건 변경 시 양측 재승인은 유지합니다. [기존 장비·매칭 요구사항](https://github.com/wookher-afk/node-test/blob/develop/unify-database-foundation/docs/requirements-node-0.1.md).

**8. 확정 가능한 방향과 남은 미확정 사항**

| 이번 근거로 권고할 수 있는 방향 | 아직 확정하지 않을 내용 |
|---|---|
| 공통 소·중·대 임시값 교체 | 장비별 전국 공통 숫자 메뉴 |
| 장비별 단위·측정조건 분리 | 굴착기 현장 호칭과 중량·버킷의 일괄 환산 |
| 작업자·업체 공통 코드 사용 | 천공기·항타기 전체를 아우르는 단일 급수 |
| 자가기사·데모기사 복수선택 유지 | 살수차·트레일러·사다리차·견인차의 공통 선택값 |
| 운전능력과 실물 장비 분리 | ‘리프트’의 정확한 서비스 범위 |
