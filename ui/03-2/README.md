## 로컬 미리보기

<http://127.0.0.1:8032/ui/03-2/> 접속. 종료는 해당 터미널에서 Ctrl+C.

## 반영한 검토사항

- 01: 장비별 형태. 굴착기 미니 / 궤도식(LC) / 타이어식(W), 형태에 맞는 규격 후보.
- 02·03: 운전능력 상태와 추가 경력 입력 삭제. 해당 장비 작업 경력(년) 유지.
  기존 개월 기록은 삭제하지 않고 이전 기록으로 보존·표시한다.
- 04: 장비별 옵션 복수 체크와 기타 입력. 운용 가능 옵션 / 실제 보유 옵션 구별.
- 06: 조사 보고서 원문과 선행 표준화 조사안을 기존 채팅에서 확보해 동봉.
  스키드로더, 그레이더, 스크레이퍼, 살수차, 구난 견인차, 트랙터,
  카고크레인, 타워크레인, 스카이차, 사다리차, 건설용 리프트, 피니셔,
  도로절삭기 추가. 기존 18항목에서 31항목으로 확장(기타 포함).
  롤러 하위 구조, 발전기 전원 조건, 지게차 하중중심 등 보조 제원 확장.
- 07: 표준명·별칭·분류 검색. 검색 결과에서 같은 고정 장비 ID 선택.
  바브캣·밥캣, 페이로더·페이로다, 추레라, 스카이, 콤프레샤 등 연결.
- 08: 기타 실제 장비명 필수(공백만 입력 불가), 등록 카드 제목에 표시.
- 09: 종류 변경 시 제조사·모델·규격·제원·옵션·경력·별칭을 분리.
  이전 장비 초안은 장비 ID별로 임시 보관하고 다시 선택하면 복원.
  새로고침 후에도 복원한다. 형태 변경 시 호환되지 않는 규격은 원문 그대로
  복원용 선택지로 보존하고 확인 안내를 표시한다. 목록에 이미 등록된 장비는 변경하지 않는다.

자가기사·데모기사 동시 선택, 운전 가능/보유 장비 분리, 복수 등록·편집·삭제,
임시저장·복원, 장비별 경력 유지. 05 하역(지게차·텔레핸들러), 10 고정 ID 및
구 숫자 ID 0~16 호환 유지. 기존 제원 배열의 앞쪽 의미·순서는 유지한다.
A안은 version 2에 aRevision 1을 추가하며 저장 키 node_03_2_a_v1을 사용한다. 이전 node_03_2_v1은 수정하지 않는다. 알 수 없는 ID는 원문 읽기·보존만 허용한다.

## 남은 28항목 통합 입력 (2026-10-30)

`equipment-schema.js`는 승인 검토본의 28개 ID(A2/B16/C10), 선택 흐름, 근거와 한계, 명명된 추가 제원을 관리합니다. `equipment.js`는 선택 상태·복수 공법/장치·직접 입력을 처리합니다. 신규 저장 키는 각 기록/초안의 `equipmentDetails`입니다. 기존 `specs` 배열과 `aSpecs`, 카고 구조는 그대로 유지합니다. 각 추가 제원은 `{status, value, choices}`로 기록하며 미입력(`''`), 직접 입력(`value`), 모름(`unknown`), 해당 없음(`na`), 미정(`pending`)을 구분합니다. 값 `"0"`을 빈값으로 취급하지 않습니다. 알 수 없는 하위 키와 선택지도 보관합니다.

검증: `node tests/ui/03-2-equipment.test.cjs`. 결과·보류 사항은 `equipment-verification.md`를 확인하세요. 기존 A안·덤프·카고·통합 테스트도 함께 실행합니다.

## 전체 등록 흐름 검수 후 일괄 수정 (2026-10-30)

사용자가 승인한 검수 D01~D06을 반영했습니다. 제조사·모델·직접 형태 등의 필수 텍스트는 공백을 제거한 뒤 확인합니다. 단위가 고정된 단일 수량 제원과 카고 mm 입력은 새 값에 0 이상의 유한한 숫자만 허용합니다. 기존 등록 기록의 변경하지 않은 원문과 자유 설명·복합 치수는 보존합니다. 잘못된 새 초안을 재진입한다고 유효한 값으로 간주하지 않습니다.

미입력·모름·해당 없음으로 바꾼 수량은 원문을 남기고 현재 상태를 카드에 표시합니다. 예전 상태 키가 없는 숫자는 원래처럼 표시합니다. 카고 길이·폭에 미입력/모름/해당 없음/직접 입력을 구별하고 실제 mm 입력에도 상태를 제공합니다. 기존 카고 빈값은 의미를 추측하지 않고 이전 응답 미확인으로 보관합니다.

상단 큰글씨 버튼은 필드명·입력·버튼·설명을 함께 확대합니다. 추가 실제 제원·근거·제조사 참고는 접어서 제공하고, 접힌 필드의 오류는 해당 영역을 열어 안내합니다. 저장 후 목록 위에서 운전/보유 장비 추가와 다음 단계로 이어갈 수 있습니다. 실제 이전·다음 가입 화면의 연결은 여전히 별도 범위입니다.

검증: `tests/ui/03-2-flow.test.cjs` F01~F08 및 기존 A안·덤프·카고·전체 장비·통합 테스트. 원본 프로필을 쓰지 않는 격리 브라우저로 실행했습니다. 결과와 제한 사항은 `docs/03-2-flow-audit-2026-10-30/fix-report.md`에 기록합니다.
