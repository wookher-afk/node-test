조사일: 2026-10-30, 한국 시간

## 먼저 읽을 내용

**현재 파일에는 32개가 아니라 31개 항목이 있다. 굴착기를 제외한 조사 대상은 30개이며, 그 안에 ‘기타’가 포함된다.** 따라서 이름이 정해진 비굴착기 장비는 29종이다. 요청한 숫자에 맞추려고 장비를 추가하거나 타 장비를 임의로 쪼개지 않았다. 아래에는 실제 존재하는 30개 항목 모두를 조사했다. 요청상 32번째 장비의 명칭은 확인되지 않았다.

핵심 결론은 ‘장비마다 다른 기준으로 현장 규격을 받자’이다. 예를 들어 지게차 3톤은 들어 올릴 수 있는 정격하중을 뜻하지만, 5톤 스카이는 차량 호칭이다. 현장 호칭, 모델명, 정확한 제원을 따로 저장해야 한다.

이번 조사로 모든 장비의 전국 공통 숫자 메뉴가 확정된 것은 아니다. **전수조사는 모든 대상 항목을 검토했다는 뜻이고, 모든 규격값의 검증 완료를 뜻하지 않는다.** 확정 근거가 부족한 항목에는 그 이유와 후속 확인 대상을 명시했다.

권고하는 검토 순서:

1. 겹치는 로더 구간, 믹서 용량의 이름, 펌프의 높이·붐 길이 구분부터 정리한다.
2. 국내 사용 근거가 있는 호칭은 검색·빠른 선택 후보로 검토한다.
3. 숫자 근거가 부족한 장비는 형태 선택과 단위 있는 직접 입력을 유지한다.
4. 사용자가 아래 제안을 검토한 후 별도로 코드 반영 범위를 결정한다.

## 4. 초보자도 고르기 쉬운 선택 UX 권고

### 4.1 선택 순서

**장비 이름 → 형태/방식 → 현장 호칭(알면 선택) → 필요한 핵심 제원 → 모델/구성 보완**을 권한다.

모델명을 몰라도 운전능력을 등록할 수 있게 한다. 보유 장비에는 명판·등록증·제원표를 보며 점진적으로 정보를 보완할 수 있게 한다. 정량값 미확인은 ‘확인 필요’로 표시하고 임의 기본값으로 채우지 않는다.

| 화면 항목 | 쉬운 안내 예시 | 처리 원칙 |
|---|---|---|
| 현장에서 부르는 규격 | ‘예: 5톤 스카이, 25톤 크레인’ | 원문 호칭 보존. 제조사 모델·정확한 수치와 별도 |
| 정확한 제원 | ‘제원표에 적힌 실제 값을 입력하세요. 모르면 비워두세요.’ | 숫자+단위+측정조건 |
| 모델 | ‘제조사와 모델명을 알고 있으면 입력하세요.’ | 숫자로 능력 추정 금지 |
| 규격을 모르겠어요 | ‘현재는 미확인으로 저장하고 나중에 보완할 수 있어요.’ | 등록 중단을 피하되 검증완료로 처리하지 않음 |

| 예시 | 현장 호칭 | 제조사·모델 | 정확한 제원 | 오해 방지 |
|---|---|---|---|---|
| 스카이 | 5톤·45m급 | 진우 JW450S | 높이 45.5m, 기본 작업하중 400kg, 반경 조건 별도 | 5톤을 작업대 하중으로 사용하지 않음 |
| 카고크레인 | 5톤 카고 | 광림 KS1256G-Ⅱ | 6,600kg/2m, 300kg/18.7m 등 | 차대 5t와 인양능력 분리 |
| 로더 | 사용자가 입력한 ○루베급 | 정확한 모델·버킷 구성 | 현재 버킷의 확인된 용량 ㎥ | 모델 표지값을 모든 버킷에 적용하지 않음 |
| 지게차 | 2.5톤 입식 | 실제 제조사·모델 | 정격하중·하중중심·마스트별 높이 | 입식·동력·하중은 각각 기록 |

### 4.4 내부 저장에 필요한 최소 정보

사용자에게 기술적인 필드를 모두 보여줄 필요는 없다. 내부적으로는 장비 ID, 형태, 호칭 원문, 호칭 종류(현장/적산/NODE 구간/사용자 입력), 제조사·모델·접미사·연식, 수치·단위·조건, 실제 장착 구성, 출처·판본·확인일·검증상태를 분리하는 안을 권한다.

단위 변환과 사양 대응은 다르다. 9.5kL=9,500L는 단위 변환이지만, ‘5톤 물차=5,000L’는 사양 추정이므로 할 수 없다. 마찬가지로 0.69MPa=6.9bar는 단위 변환이지만, 서로 다른 판본의 0.69MPa와 0.7MPa 중 하나를 해당 실물 사양으로 고르는 것은 별도 검증이 필요하다.

## 6. 추후 코드 반영 범위 선택안

지금 어느 안도 실행하지 않았다. 아래 중 원하는 범위를 정하면 별도 구현 작업으로 진행할 수 있다.

| 선택안 | 포함 내용 | 판단할 점 |
|---|---|---|
| A. 오류·용어부터 정리 — 우선 권고 | 개수 설명, 로더 중복 구간, 믹서 용량, 고소 명칭, 펌프 높이/길이, 근거 표시 | 새 숫자를 대량 추가하지 않고 현재 오해를 줄이는 범위 |
| B. 검증된 후보까지 추가 | A + 형태별 크레인 후보, 리프트 모델별 후보, 텔레핸들러 고정/회전, 카고크레인 호칭 | 업체 사례와 제조사 값을 구분한 화면 설계 필요 |
| C. 입력·저장 구조까지 보완 | B + 수치/단위/조건 분리, 미확인 상태, 모델·구성별 출처 | 기존 입력 기록 보존·이전 계획과 별도 검증 필요 |

현재 연구의 권고는 A부터 검토하는 것이다. 조사표에 있는 숫자를 한꺼번에 메뉴로 옮기면 R 적산값·B 업체 호칭·A 모델 제원이 다시 섞인다.

## 7. 조사 한계와 보존 원칙

이 보고서는 공개 원문을 중심으로 한 서면 조사다. 현장 인터뷰, 유료 자료, 장비 명판·등록증·개별 실물 검사는 포함하지 않았다. 국내 근거가 부족한 장비는 해외 공식 제원으로 기술적 기준을 보완했으나 국내 보급·현장 표준으로 승격하지 않았다. 일부 동적 페이지·다운로드는 본문 접근이 제한됐고, 해당 주장은 표에서 범위를 좁혔다. 원문 접근 실패는 자료가 없다는 뜻이 아니다.

구인 자료는 지게차에서 직접 채용 제목을 확인했다. 다른 장비의 용어 근거는 주로 제조사·국내 공급·임대·직접 판매 자료다. 이번 조사가 29종 모두의 현행 구인 용어를 별도로 검증한 것은 아니다.

면허·법률·안전 작업 가능 판정은 이번 현장 규격 조사 범위에서 새로 확정하지 않았다. 최대 제원값 하나만으로 특정 현장 작업이 가능하다고 판정하지 않는다.

코드·기존 보고서·Git 이력은 그대로 두었다. 이 보고서의 제안은 향후 사용자가 선택한 범위에 한해서만 코드 반영을 검토한다.
