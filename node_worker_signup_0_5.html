NODE 작업자 등록 0.5

직종·운전 가능 규격·보유 장비를 각각 등록하는 자동 매칭용 테스트 페이지

가입은 간단하게 시작할 수 있습니다. 모든 정보를 한 번에 입력할 필요는 없습니다. 테스트 데이터는 이 브라우저에만 저장되며 실제 회원가입이나 서버 전송은 이루어지지 않습니다.

01. 기본 정보

시·도와 시·군·구를 선택한 후 추가하세요. 예: 경남 합천군, 대구 남구. 선택한 시·군·구 전역이 대상입니다.

02. 수행 가능한 직종

직종을 여러 개 등록할 수 있습니다. 굴착기처럼 장비가 필요한 직종은 운전 가능한 규격을 복수 선택할 수 있습니다. 이는 보유 장비와 별개입니다.

03. 실제 보유 장비

장비가 없다면 비워 두세요. 여러 대를 소유한 경우 한 대씩 추가하면 됩니다. 동일 규격도 여러 대 등록할 수 있습니다.

04. 면허·자격

면허는 여러 개 등록할 수 있습니다. 취득일과 증빙 여부를 구분합니다.
